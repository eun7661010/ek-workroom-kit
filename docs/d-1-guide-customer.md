# 전날 준비: 원장님 혼자 20~30분
원장님 본인 유료 구독으로 진행합니다. 판매자는 비밀번호·인증 코드·학생 파일을 받지 않습니다. 학생 폴더·메신저·이메일은 닫고 중요 자료를 백업해 주세요. 오늘 고를 업무는 A~E 중 한 개이며, 샘플은 직접 개인정보를 지운 것만 준비합니다.

## 판매자가 보낸 블록 하나 붙여넣기
판매자가 메신저로 보내는 **내 PC용 붙여넣기 블록 전체**를 Windows PowerShell 또는 Mac 터미널에 한 번 붙여 넣습니다. Windows/Mac을 확인한 뒤 맞는 블록만 씁니다. 이 안내문에서 해시 빈칸을 채우는 작업은 하지 않습니다.

블록은 HTTPS에서 bootstrap 파일을 받습니다. 이어서 **메신저 블록 안의 기대 SHA256**과 자동 비교하고, 다르면 실행하지 않고 멈춥니다. 같을 때만 받은 스크립트의 **DryRun(설치 없는 미리보기)**을 실행합니다. 블록은 메신저, 파일은 HTTPS로 따로 받으므로 같은 다운로드 안의 해시만 믿는 구조가 아닙니다.

판매자용 원본은 릴리스 도구가 만든 `paste-block-windows.txt` 또는 `paste-block-mac.txt`입니다. `example.invalid`가 들어 있으면 배포 주소 미확정본이므로 실행하지 말고 판매자에게 완성 블록을 요청하세요. Windows에서 스크립트는 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File`로 한 번 실행하며 실행 정책을 영구 변경하지 않습니다. 관리자 조직 정책은 변경하지 않습니다.

## 미리보기 다음
미리보기 4단계(키트 검증·고정 위치 배치→Claude 확인/설치→Codex 확인/설치→진단)를 직접 읽고 원장님이 승인한 경우에만 화면에 나온 로컬 키트·해시를 사용하는 Apply 재실행 명령을 실행합니다. 자동으로 설치하지 않습니다. Claude Code와 Codex CLI는 각각 있으면 유지하고, 없을 때만 공식 설치 파일을 별도 프로세스로 실행합니다. Codex 설치가 실패해도 Claude는 유지하고 “Codex 설치 미완료”를 표시한 뒤 진단을 계속합니다. Node/Python/Git은 설치·업그레이드하지 않습니다. Windows Git은 선택이며 관리자 권한을 요구하지 않습니다. Mac은 기존 Python3가 없으면 멈추고 판매자에게 알립니다.

키트는 `<홈>/ek-workroom/kit-0.2.0`에 배치되며 **완전한 경로가 화면에 나옵니다**. 이미 같은 위치가 있으면 덮어쓰지 않고 멈춥니다. 다시 설치를 반복하지 말고 그 위치의 키트를 사용해 판매자에게 상황을 알려 주세요. 다운로드 파일과 임시 검증 파일은 그 홈의 ek-workroom 아래에 둡니다.

## 직접 로그인하기
설치 뒤 새 터미널에서 `claude`를 엽니다. 브라우저가 안 열리면 `c`로 표시된 로그인 URL을 복사해 직접 엽니다. 브라우저에 승인 코드가 나오면 **판매자에게 보내지 말고 본인 Claude 터미널의 `Paste code here if prompted`에 붙여 넣습니다**. 로그인 중 화면 공유를 끕니다.

Codex는 당일 시작 10~30분 구간에 본인 ChatGPT 계정으로 로그인합니다. 브라우저 연결이 막히면 `codex login --device-auth`를 실행하고 표시된 공식 주소와 코드를 본인이 직접 사용합니다. 계정을 다른 강사와 공유하지 않습니다. 기존 브라우저 세션·비밀번호·코드·인증 파일을 판매자에게 주지 않습니다.

## 진단 보내기
홈에 생성된 `ek-diag.txt`의 첫 줄 “보내기 전에 직접 읽어 보세요”를 보고 내용을 읽습니다. OS·도구 버전·PATH 개수·디스크 여유·실행 정책·보안 SW·두 서비스 도달 여부만 있어야 합니다. 파일 내용·목록·이름·이메일·전화번호·IP·홈 경로가 보이면 보내지 않습니다. 원장님이 확인한 마스킹 결과만 직접 붙여 넣습니다. 자동 전송은 없습니다.

## 학생 폴더를 보호할 때
원장님이 실제로 존재하는 학생 폴더 경로를 로컬 프로필에 넣습니다. 드라이브 전체와 홈 전체는 넣을 수 없습니다. 스크립트는 내용이나 파일 목록을 읽지 않고 입력 경로와 연결된 실제 경로만 확인해 둘 다 deny에 넣습니다. Mac 한글은 두 정규화 형태를 함께 차단합니다.

**Claude의 차단은 OS 권한 보호가 아닙니다. 셸 승인 요청에서 학생 폴더 경로가 보이면 거절하세요.** 적용 뒤 `/permissions` 확인과 개인정보 없는 시험 파일의 Read 차단을 먼저 확인합니다. 차단되지 않으면 실자료 작업을 시작하지 않습니다.

## 직접 비교하는 대안
자동 붙여넣기가 어려울 때만 판매자가 준 스크립트를 파일로 받고 아래 명령으로 SHA256을 표시해 별도로 받은 64자 값과 대조합니다. 같을 때만 판매자가 준 DryRun 명령을 실행합니다.
```powershell
Get-FileHash ./bootstrap.ps1 -Algorithm SHA256
```
```sh
shasum -a 256 ./bootstrap.sh
```

## 막히면
해시가 다름→실행 중지. 같은 위치가 있음→기존 키트 경로 확인. 로그인 실패→본인 계정 지원으로 해결. 보안 프로그램·회사 정책 차단→PC 관리자에게 문의. 오류는 개인정보를 지운 한 줄과 마지막 성공 단계만 전달합니다. 보안 프로그램과 실행 정책을 통째로 끄지 않습니다. 당일 165분과 버퍼, 본인 휴대폰과 안정적인 인터넷을 준비합니다.
