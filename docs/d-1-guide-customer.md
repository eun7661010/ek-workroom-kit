# 전날 준비: 원장님 혼자 20~30분
원장님 본인 유료 구독으로 진행합니다. 판매자는 비밀번호·인증 코드·학생 파일을 받지 않습니다. 학생 폴더·메신저·이메일은 닫고 중요 자료를 백업해 주세요. 오늘 고를 업무는 A~E 중 한 개이며, 샘플은 직접 개인정보를 지운 것만 준비합니다.

## 판매자가 보낸 블록 하나 붙여넣기
판매자가 메신저로 보내는 **내 PC용 붙여넣기 블록 전체**를 Windows PowerShell 또는 Mac 터미널에 한 번 붙여 넣습니다. Windows/Mac을 확인한 뒤 맞는 블록만 씁니다. 이 안내문에서 해시 빈칸을 채우는 작업은 하지 않습니다.

Windows는 **Windows 키 → `PowerShell` 검색 → `Windows PowerShell` 일반 실행**으로 창을 엽니다(관리자 실행 아님). 파란색 또는 검은색 창에서 `PS C:\...>`처럼 보이는 명령 입력 줄을 확인하세요. 메신저의 코드 블록 전체를 복사한 뒤 그 창에 `Ctrl+V`로 붙여 넣습니다. 안 되면 창 안에서 마우스 오른쪽 버튼을 누릅니다. 여러 줄 붙여넣기 경고가 뜨면 판매자가 준 블록 전체인지 확인하고 붙여넣기를 선택한 뒤 `Enter`를 누릅니다. Claude 대화창이나 탐색기 주소창에는 이 블록을 붙이지 않습니다. 직접 입력하는 짧은 명령은 영문 입력 상태에서 치고, 블록의 따옴표는 다시 치거나 바꾸지 않습니다.

블록은 HTTPS에서 bootstrap 파일을 받습니다. 이어서 **메신저 블록 안의 기대 SHA256**과 자동 비교하고, 다르면 실행하지 않고 멈춥니다. 같을 때만 받은 스크립트의 **DryRun(설치 없는 미리보기)**을 실행합니다. 블록은 메신저, 파일은 HTTPS로 따로 받으므로 같은 다운로드 안의 해시만 믿는 구조가 아닙니다.

판매자용 원본은 릴리스 도구가 만든 `paste-block-windows.txt` 또는 `paste-block-mac.txt`입니다. `example.invalid`가 들어 있으면 배포 주소 미확정본이므로 실행하지 말고 판매자에게 완성 블록을 요청하세요. Windows에서 스크립트는 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File`로 한 번 실행하며 실행 정책을 영구 변경하지 않습니다. 관리자 조직 정책은 변경하지 않습니다.

## Mac 사전 준비: Apple 개발 도구
Mac은 Apple 공식 개발 도구(Command Line Tools)에 들어 있는 python3(기본 3.9.6)를 사용합니다. Homebrew 등의 python3가 이미 있고 3.9 이상이면 그대로 사용합니다. Windows에는 Python이 필요하지 않습니다.

개발 도구가 없으면 키트는 설치 창을 띄우거나 설치하지 않고, 미리보기와 설치 모두 안내 후 멈춥니다. **터미널에 `xcode-select --install`을 직접 입력하고 뜨는 창에서 '설치'를 누르세요(약 10분, Apple 공식). 끝나면 판매자가 보낸 블록 전체를 다시 붙여 넣으세요.**

## 미리보기 다음
미리보기 4단계(키트 검증·고정 위치 배치→Claude 확인/설치→Codex 확인/설치→진단)를 직접 읽습니다. **동의하면 계획 마지막에 나온 Apply 명령 한 줄 전체를 복사해 PowerShell 창(Mac은 터미널)에서 실행합니다.** 이때 표시된 경로는 설치 예정 위치이며 미리보기만으로 설치되지는 않습니다. Claude Code와 Codex CLI는 각각 있으면 유지하고, 없을 때만 공식 설치 파일을 별도 프로세스로 실행합니다. **설치 진행 내용은 현재 창에 표시됩니다. 완료 안내까지 창을 닫지 마세요.** Codex 설치가 실패해도 Claude는 유지하고 “Codex 설치 미완료”를 표시한 뒤 진단을 계속합니다. 키트는 Node/Python/Git을 설치·업그레이드하지 않습니다. Windows Git은 선택이며 관리자 권한을 요구하지 않습니다. Mac에서 python3가 없다는 안내가 나오면 위의 Apple 개발 도구 설치를 직접 마친 뒤 판매자가 보낸 블록을 다시 붙여 넣습니다.

키트는 `<홈>/ek-workroom/kit-0.2.3`에 배치되며 **완전한 경로가 화면에 나옵니다**. 설치 도중 실패하면 마지막 성공 단계와 오류 한 줄을 남긴 뒤, 원인 해결 후 같은 Apply 명령으로 이어 할 수 있습니다. 같은 버전 폴더의 모든 파일 내용 확인값이 받은 키트와 같을 때만 기존 폴더를 재사용하며, 다르면 멈춥니다. 폴더를 지우거나 덮어쓰지 말고 판매자에게 상황을 알려 주세요. 다운로드 파일과 임시 검증 파일은 그 홈의 ek-workroom 아래에 둡니다.

## 직접 로그인하기
설치 뒤 **새 PowerShell 창**(Mac은 새 터미널)에서 `claude`를 입력합니다. 로그인 뒤에는 **Claude 입력란**으로 바뀝니다. 브라우저가 안 열리면 `c`로 표시된 로그인 URL을 복사해 직접 엽니다. 브라우저에 승인 코드가 나오면 **판매자에게 보내지 말고 본인 Claude 터미널의 `Paste code here if prompted`에 붙여 넣습니다**. 로그인 중 화면 공유를 끕니다.

Codex는 당일 시작 10~30분 구간에 **별도의 새 PowerShell 창 또는 탭**에서 `codex`를 입력해 본인 ChatGPT 계정으로 로그인합니다. Claude 입력란에 `codex`를 쓰지 않습니다. 브라우저 연결이 막히면 PowerShell 창에서 `codex login --device-auth`를 실행하고 표시된 공식 주소와 코드를 본인이 직접 사용합니다. 끝나면 기존 Claude 창으로 돌아옵니다. 계정을 다른 강사와 공유하지 않습니다. 기존 브라우저 세션·비밀번호·코드·인증 파일을 판매자에게 주지 않습니다.

## 진단 보내기
화면의 “진단 파일” 뒤에 나온 전체 경로에서 `ek-diag.txt`를 엽니다. Windows는 **파일 탐색기 열기 → 주소창에 `%USERPROFILE%` 입력 → Enter → `ek-diag.txt`를 마우스 오른쪽 버튼으로 눌러 메모장으로 열기**로 찾습니다. 첫 줄 “보내기 전에 직접 읽어 보세요”를 보고 내용을 읽습니다. OS·도구 버전·PATH 개수·디스크 여유·실행 정책·보안 SW·두 서비스 도달 여부만 있어야 합니다. 파일 내용·목록·이름·이메일·전화번호·IP·홈 경로가 보이면 보내지 않습니다. 화면에 표시된 저장 경로는 보내지 말고 파일 안의 마스킹 결과만 직접 붙여 넣습니다. 자동 전송은 없습니다.

## 학생 폴더를 보호할 때
원장님이 실제로 존재하는 학생 폴더 경로를 로컬 프로필에 넣습니다. 드라이브 전체와 홈 전체는 넣을 수 없습니다. 스크립트는 내용이나 파일 목록을 읽지 않고 입력 경로와 연결된 실제 경로만 확인해 둘 다 deny에 넣습니다. Mac 한글은 두 정규화 형태를 함께 차단합니다.

차단 시험은 원장님이 개인정보 없는 연습 폴더를 만들고 **학생 폴더로 지정한 뒤, 그 연습 폴더 안에** 메모장으로 `차단확인.txt`를 직접 만들어 합니다. AI에게 시험 파일을 만들게 하거나 보호 대상 밖의 파일을 시험하지 않습니다.

**Claude의 차단은 OS 권한 보호가 아닙니다. 셸 승인 요청에서 학생 폴더 경로가 보이면 거절하세요.** 적용 뒤 Claude 입력란에서 `/permissions`를 확인하고 위 시험 파일의 Read 차단을 먼저 확인합니다. 차단되지 않으면 실자료 작업을 시작하지 않습니다.

## 직접 비교하는 대안
자동 붙여넣기가 어려울 때만 판매자가 준 스크립트를 파일로 받고 아래 명령으로 SHA256을 표시해 별도로 받은 64자 값과 대조합니다. 같을 때만 판매자가 준 DryRun 명령을 실행합니다.
```powershell
Get-FileHash ./bootstrap.ps1 -Algorithm SHA256
```
```sh
shasum -a 256 ./bootstrap.sh
```
