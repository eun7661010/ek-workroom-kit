# 전날 준비: 원장님 혼자 20~30분
「원장님 AI 작업실 개통」은 80만 원 1:1 원격 상품의 시제품입니다. 설치비 외 AI 구독료는 고객이 별도로 부담합니다. 이 안내의 빈칸은 판매자가 확정한 파일·해시·일정으로 채운 뒤 사용합니다. 시제품은 깨끗한 Windows·Mac에서 실제 설치 실측 전이며 상용 완료본으로 안내하지 않습니다.

1. 학생 폴더·카카오톡·이메일을 닫고 중요 파일 백업을 확인합니다. Zoom은 작업 창만 공유하고 녹화는 끕니다. 화면 공유를 언제든 멈출 수 있습니다.
2. 고객 본인 Claude 유료 구독과 Codex를 지원하는 고객 본인 ChatGPT 계정을 준비합니다. 비밀번호·휴대폰 인증은 직접 입력하며 판매자에게 말하거나 보내지 않습니다. 계정을 다른 강사와 공유하지 않습니다.
3. Windows 10/11 또는 macOS 버전, 저장공간, 보안 프로그램 이름을 확인합니다. 권장 여유 공간 20GB·메모리 16GB는 상품 준비 기준 가정이며 진단으로 적합 여부를 확인합니다. 회사 관리 PC면 관리자에게 먼저 문의합니다.
4. 업무 A~E 중 한 개를 고르고 실명·전화번호·이메일을 지운 샘플 3~5개만 준비합니다. 학생 폴더 위치는 고객 PC에만 적습니다. 판매자 AI에는 보내지 않습니다.

## 파일을 받은 뒤 해시 확인
판매자는 고정 버전의 `bootstrap.ps1`(Mac: `bootstrap.sh`), 키트 ZIP 주소, 각 파일의 SHA256 64자 값을 제공합니다. **해시는 파일 다운로드 메시지와 별도 메신저 메시지 또는 Zoom 음성으로 확인합니다.** 같은 ZIP 안의 해시만 믿지 않습니다.
아래 `<...>`는 판매자가 제공한 실제 값으로 바꿉니다. 다운로드와 해시 출력은 한 줄씩 복사하되 해시 확인 전에 실행 줄을 붙이지 마세요.

Windows PowerShell:
```powershell
Invoke-WebRequest "<판매자가 준 bootstrap.ps1 HTTPS 주소>" -OutFile .ootstrap.ps1
Get-FileHash .ootstrap.ps1 -Algorithm SHA256
```
표시된 값이 따로 받은 **스크립트 해시**와 64자 모두 같을 때만:
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .ootstrap.ps1 -Source "<키트 ZIP HTTPS 주소 또는 로컬 ZIP>" -ExpectedSha256 "<따로 받은 ZIP SHA256>" -DryRun
```
Mac 터미널:
```sh
curl -fsSL "<판매자가 준 bootstrap.sh HTTPS 주소>" -o bootstrap.sh
shasum -a 256 bootstrap.sh
```
**스크립트 해시**가 같을 때만:
```sh
bash ./bootstrap.sh --source "<키트 ZIP HTTPS 주소 또는 로컬 ZIP>" --expected-sha256 "<따로 받은 ZIP SHA256>" --dry-run
```
키트 ZIP의 해시도 스크립트가 다시 확인합니다. 하나라도 다르면 멈추고 판매자에게 알립니다. 폴더 소스도 지원하지만 초급 고객은 판매자가 릴리스 도구로 만든 ZIP을 사용합니다.

## 미리보기 다음
DryRun은 설치하지 않습니다. 다운로드한 ZIP을 확인하고 계획을 표시하며 진단 리포트·임시 파일을 만들 수 있습니다. 계획과 설치 항목을 읽고 판매자와 확인한 뒤, 원장님이 승인한 경우에만 같은 명령에서 `-DryRun`을 `-Apply`(Mac: `--apply`)로 바꿉니다. 실제 설치는 Claude Code 공식 설치 스크립트만 사용하며 Node/Python은 설치·업그레이드하지 않습니다. Mac에서 기존 Python3가 없으면 안전 검증을 진행할 수 없어 멈춥니다. 임의로 설치하지 말고 판매자에게 문의하세요.
Claude가 설치되어 있으면 다시 설치하지 않습니다. 설치 후 `claude`를 직접 열어 본인 구독 로그인을 시도합니다. 브라우저가 열리지 않으면 표시된 로그인 주소를 직접 엽니다. 비밀번호·인증 코드가 보일 때 화면 공유를 끕니다.

## 진단 보내기
`ek-diag.txt` 맨 위 “보내기 전에 직접 읽어 보세요”를 보고 내용을 직접 읽습니다. OS·도구 버전·PATH 개수·디스크 여유·실행 정책·보안 SW·두 서비스 도달 여부만 있어야 합니다. 파일 내용·파일 목록·이름·이메일·전화번호·IP·집 경로가 보이면 보내지 않습니다. 마스킹된 결과만 고객이 직접 붙여 넣으며 자동 전송은 없습니다. 기존 `kit/report.json` 원본 대신 이 진단을 공유합니다.

## 막히면
해시 불일치→실행 중지. 로그인 실패→고객이 계정 지원으로 해결. 보안 프로그램 차단→PC 관리자에게 문의. 스크립트 오류→개인정보를 지운 오류 한 줄과 성공한 단계만 판매자에게 보냅니다. 보안 프로그램·실행 정책을 통째로 끄지 않습니다. 당일 휴대폰·안정적인 인터넷·165분과 버퍼를 준비합니다.
