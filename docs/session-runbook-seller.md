# 판매자 진행표: 165분 목표
시제품 v0.2.2입니다. 시간은 설계 추정이며 세 번의 실제 설치와 모의 세션 실측 전 판매 완료 조건을 충족하지 않습니다. 고객 본인 AI만 고객 PC를 처리하고 판매자 AI에는 고객이 읽고 붙인 마스킹 진단만 제공합니다. 판매자 AI가 고객 화면·파일을 받지 않게 화면 캡처·파일 첨부·자동 기록을 끕니다. 판매자는 Zoom 작업 창으로 감독합니다.

## 세션 전
D-7: 사전 설문으로 업무 A~E 한 개, OS, 요금제, 보안 SW를 확인하고 고객 로컬 프로필과 더미 시안을 준비합니다. 차단 경로는 고객이 로컬에서 채우며 판매자 AI에 넘기지 않습니다.
D-3: 고정 버전 validate·전체 테스트 결과를 기록합니다. HTTPS 릴리스 주소를 넣어 make-release가 만든 paste-block-windows.txt 또는 paste-block-mac.txt 한 블록을 메신저로 안내합니다. 수동 해시 대조는 대안입니다. 배포·외부 전송은 운영 승인을 받은 경로에서만 수행합니다.

세션 콘솔은 `console/session-console.md`를 복사합니다. 고객 실명 대신 세션 번호만 쓰며 프로필·학생 경로·로그인·화면을 콘솔에 저장하지 않습니다. Zoom 호스트의 시간 제한과 유료 호스트 계정을 사전 확인합니다.

## 실행 순서
고객이 작업실에서 `claude`를 엽니다. 키트 고정 위치는 bootstrap이 출력한 **그 절대 경로**이며 `/plugin marketplace add "<키트 절대 경로>"` → `/plugin install ek-workroom@ek-workroom`을 수행합니다. 신뢰 확인 창에서 버전·출처를 검수합니다. 설치와 스킬 표시를 확인한 뒤 필요하면 Claude를 재시작합니다.
`/ek-workroom:ek-start` → `ek-safety` → `ek-mode` → `ek-codex-link` → `ek-flow` → `ek-handoff` 순서입니다. 뒤 명령도 `/ek-workroom:` 접두사를 붙입니다. 프로필·고객 홈은 로컬에서만 전달합니다. 10~30분에 ek-start에서 부트스트랩 설치 결과와 본인 로그인을 확인하고, 60~70분 ek-codex-link에서는 반복 설치 없이 교차 검토만 합니다. D-1 진단을 이미 읽었고 환경이 같으면 ek-start에서 다시 수집하지 않습니다.
권한 변경은 결정적 스크립트로만 수행하며 미리보기→설명→해당 항목 승인→적용→확인의 순서를 지킵니다. **이 시제품 개발·테스트에서는 실제 홈 -Apply를 실행하지 않습니다.** 고객 세션 적용도 실제 설치 검증과 출시 승인 이후입니다.

## 안전 규칙과 한계
**Claude 차단은 OS 권한 보호가 아닙니다. 셸 승인 요청에서 학생 폴더 경로가 보이면 거절하세요.** Read/Edit deny는 지정 도구 규칙입니다. 적용 후 /permissions를 먼저 확인하며 개인정보 없는 시험 파일 Read가 차단된 후 Edit를 시험합니다. 셸·외부 도구가 학생 폴더를 읽는 것까지 OS가 막아 주지 않습니다. 키트는 Bash/PowerShell/WebFetch/WebSearch/MCP 전체를 ask로 묶으므로 조회 명령도 자주 묻습니다. 학생 경로 접근·삭제·이동·git push·외부 전송이 담긴 명령은 거절합니다. 안전 기능 해제 옵션은 사용하지 않습니다. 정책 충돌 시 고객 관리자를 부릅니다.
실제 로그인은 고객이 `/status`와 `codex login status`에서 직접 확인합니다. Codex 읽기 전용도 개인정보 읽기 차단을 보장하지 않으므로 비식별 작업실과 입력만 씁니다.
선택 업무 A 상담/안내문, B 공지+대상 표, C 주간 수업 보고, D 블로그 원고, E 학습지 HTML/PDF 중 한 개입니다. 발송·게시·결제·수납 원장 반영은 하지 않습니다.

## 지연·인계
같은 오류 3회는 원인 재검토, 도구 문제 30분은 대안 전환입니다. 핵심 Claude가 안 되면 재예약합니다. 플로우 미완성은 최대 30분 무료 연장→7일 안 무료 보충 최대 90분으로 계획하고 적용 계약을 확인합니다. 보충 뒤 단독 재실행 미완성은 플로우 몫 25만 원 환불, 판매자 측 핵심 설치 실패는 전액 환불이라는 상품 설계를 계약에 명시한 경우 그대로 적용합니다. 예약·환불·추가 청구는 이 키트가 실행하지 않습니다.
마무리에 2주 뒤 1시간 점검, 30일 메신저 지원(영업일 1회, 성수기 2영업일)을 안내하고 미완료 항목을 별도로 읽어 줍니다. ‘완료’는 원장 단독 재실행과 종료 확인 후에만 표시합니다.

## 로그인·종료 확인 보충
Claude 브라우저가 열리지 않으면 c로 로그인 URL을 복사하고 고객이 직접 엽니다. 승인 코드는 판매자에게 주지 않고 본인 터미널의 Paste code here if prompted에 붙입니다. Codex는 codex login --device-auth를 사용합니다. 설치 후에는 새 터미널·Claude에서 버전을 확인합니다.
Mac SSH 상태를 일반 권한으로 확정할 수 없으면 시스템 설정 > 일반 > 공유 > 원격 로그인 화면을 고객이 직접 확인하고 콘솔의 수동 확인 칸에 적습니다. 보조 프로세스 검사의 미발견을 서버 비활성 증명으로 쓰지 않습니다. Quick Assist와 Zoom 공유도 고객이 직접 종료합니다.

작업실은 ek-mode에서 apply-workspace 미리보기·승인·적용으로 만듭니다. CLAUDE.md의 @AGENTS.md와 네 폴더·검토 양식·실행법을 확인합니다. cross-check는 브리프 저장 승인과 맞는 지적의 새 파일 반영 승인을 따로 받습니다. PDF 업무는 ek-pdf로 실제 PDF를 만든 뒤 전 쪽을 엽니다. 창 배치는 Windows Terminal이 있으면 Alt+Shift+=, 아니면 창 두 개입니다. Windows 실제 Codex read-only 실행은 새 로컬 사용자 리허설에서 확인합니다.
