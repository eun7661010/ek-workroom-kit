# 내 AI 작업실 사용 가이드 v0.1
이 가이드는 약 24쪽 가이드북으로 발전시키기 위한 실제 사용 초안입니다. PDF 24쪽 완성본은 포함하지 않습니다. 고객 본인 유료 계정으로 쓰고 비밀번호·인증 코드는 직접 입력합니다. 학생정보가 없는 작업실에서 시작하세요. 고객이 결과를 검수하고 발송·게시합니다.

## 1. 작업 창 열기와 패널 나누기
이미 설치된 Warp를 엽니다. 메뉴의 새 탭/패널 분할로 왼쪽은 Claude, 오른쪽은 Codex를 둡니다. 메뉴 이름이 다르면 창 두 개를 나란히 놓아도 됩니다. 한글이 깨지면 설정에서 이미 설치된 한글 글꼴을 골라 “한글 확인”을 입력합니다. 이 키트는 Warp·글꼴을 자동 설치하지 않습니다.

## 2. 작업 폴더 이동과 파일 찾기
Windows는 `cd "<고객이 정한 AI작업실>"`, Mac도 `cd "<고객이 정한 AI작업실>"`로 이동합니다. `ls`는 현재 작업실의 비식별 파일을 확인할 때만 씁니다. 홈 전체나 학생 폴더 목록은 열지 않습니다. Everything이 이미 있으면 고객이 직접 필요한 비식별 파일 이름만 검색합니다. 결과를 AI에 통째로 붙이지 않습니다.

## 3. Claude 시작·종료·이어 하기
작업실에서 `claude`로 시작합니다. 진행을 멈추려면 Esc를 누르고, 종료는 화면에 표시된 종료 방법을 따릅니다. `/resume`은 이전 대화를 고르고, `/clear`는 새 주제로, `/compact`는 긴 대화를 정리할 때 사용합니다. 이전 대화에 개인정보가 있다면 재사용하지 않습니다. 실제 로그인 상태는 본인이 `/status`로 확인합니다.

## 4. 스킬 부르기
`/ek-workroom:parent-message` 다음에 목적·대상 번호·확정 일정·원하는 길이를 적습니다. 예: “2반 보강 안내, 일정은 아직 미정, 120자 초안”. 플러그인 스킬은 `/ek-workroom:` 접두사를 씁니다. `/plugin`에서 설치 상태를 확인하고, 목록이 안 보이면 저장 후 Claude를 다시 시작합니다.

기본 12개:
| 스킬 | 쓰는 일 |
|---|---|
| korean-review | 맞춤법·문체 후보와 보호 구간 보고 |
| offline-spacing | 기존 Kiwi가 있을 때 외부 전송 없는 띄어쓰기 후보 |
| parent-message | 학부모 안내·상담 문자 초안 |
| director-column | 원장 문체 칼럼·블로그 원고 |
| blog-copy | 사람이 붙여 넣을 원고·HTML |
| explanation-draft | 정답·오답 근거 해설 초안 |
| question-draft | 국어 문항 초안과 검증표 |
| hwp-convert | 기존 지원 도구로 한글 문서 읽기·변환 |
| worksheet-pdf | 학습지 HTML과 브라우저 인쇄 PDF |
| scan-cleanup | 기존 PDF 도구로 스캔 보정 |
| spreadsheet-check | 비식별 표 정리·가상 입금 대조 |
| lesson-slides | 설명회·수업 슬라이드 초안 |

선택 도구는 기본팩에 설치하지 않습니다. 선택 목록만 제공합니다: 시험지 HWPX 빌드, PDF·이미지 글자 추출, 강의 영상 받아쓰기. 도구·장비·권리 조건은 별도 상담합니다.

## 5. 승인 화면 읽기
“어떤 파일인가, 무엇을 바꾸는가, 원본이 남는가, 외부로 보내는가”를 읽고 이해한 것만 승인합니다. 학생 경로 읽기, 삭제·이동, git push, 외부 전송, 모르는 설치 명령이면 거절하고 문의합니다. 이 키트는 모든 셸·웹·MCP 호출에 승인을 요청하므로 조회도 자주 물을 수 있습니다. 불편해도 안전 기능을 끄지 않습니다.
Read/Edit deny는 Claude 도구 규칙이며 운영체제 전체 차단이 아닙니다. 셸이나 다른 프로그램에 학생 폴더 읽기를 허용하면 정보가 보일 수 있습니다. 차단 시험은 고객이 준비한 개인정보 없는 시험 파일만 씁니다.

## 6. Codex와 교차 검토
`codex`를 열어 본인 ChatGPT 구독으로 로그인합니다. 비밀번호·인증 코드가 보일 때 공유를 끕니다. 검토할 초안과 근거를 개인정보 없이 같은 작업실에 둡니다. 판매자가 준비한 `review-brief.md`에 목표·입력·금지·완료 기준을 채웁니다.
도움말 `codex exec --help`에서 지원을 확인하고, 승인 뒤 `codex exec --sandbox read-only "이 비식별 초안의 날짜와 누락을 검토해 주세요"`를 사용합니다. 읽기 전용도 모든 읽기를 막는 것은 아닙니다. 학생정보를 검토 입력에 넣지 않습니다. Claude가 지적을 원문과 비교하고 원장이 최종 판단합니다.

## 7. 계정 확인·전환
상태줄 “업무용/개인용”은 원장님이 고른 수동 별칭입니다. 실제 로그인 계정이 맞는지는 `/status`와 Codex 화면에서 원장님만 확인합니다. 본인 소유·본인 결제 계정 사이에 업무/개인을 나눌 필요가 있으면 공식 로그아웃/로그인으로 직접 전환합니다. 판매자가 인증 파일을 복사하거나 계정을 대신 쓰지 않습니다. 계정 공동 사용과 자동 전환 도구는 제공하지 않습니다.

## 8. 모델과 사용량
현재 모델은 상태줄과 도구 화면에서 확인합니다. 모델 변경·사용량 확인 명령은 현재 CLI 도움말·메뉴를 따릅니다. 작업을 하나씩 나누고 목적·입력·완료 기준을 먼저 쓰면 불필요한 재생성을 줄일 수 있습니다. 불필요한 긴 파일은 붙이지 않습니다. 요금제 한도와 사용 가능 기능은 고객 계정의 실제 화면이 기준이며 추가 사용료 옵션을 임의로 켜지 않습니다.

## 9. 업데이트
업데이트 전에 열린 작업을 저장하고 결과 파일을 백업합니다. 네이티브 Claude는 공식 자동 업데이트 동작을 따릅니다. 수동 업데이트·플러그인 변경은 판매자와 버전을 확인하고 계획을 읽은 뒤 직접 승인합니다. 업데이트 후 `claude --version`, 스킬 표시, 상태줄, 더미 업무, 차단 시험을 확인합니다. 원래 설정을 초기화하거나 Node/Python을 새로 설치하지 않습니다.

## 10. 자주 막히는 열 가지
| 증상 | 먼저 할 일 |
|---|---|
| claude 명령을 못 찾음 | 설치를 반복하지 말고 새 터미널을 열어 재확인 |
| codex 명령을 못 찾음 | 버전 확인 후 미설치라면 판매자와 공식 설치 계획 확인 |
| 로그인 만료 | 화면 공유를 끄고 본인이 다시 로그인 |
| 로그인 브라우저가 안 열림 | CLI가 표시한 공식 로그인 주소를 직접 열기 |
| 휴대폰 인증 지연 | 본인 휴대폰·계정 지원 확인; 코드를 판매자에게 보내지 않기 |
| 한글·공백 경로 오류 | 고객이 정한 경로를 따옴표로 감싸기; 홈 이름 변경 금지 |
| 실행 정책 차단 | 정책을 영구 변경하지 말고 안내된 파일 단위 명령을 판매자와 확인 |
| 프록시·보안 SW 차단 | 관리 담당자에게 문의; 보안 프로그램 끄지 않기 |
| 스킬·상태줄이 안 보임 | 저장 후 재시작, 플러그인 버전 확인 |
| PDF 글자 깨짐·잘림 | 기존 한글 글꼴·A4·배율을 확인하고 전 페이지 다시 열기 |
같은 오류 3회면 멈추고 마스킹된 오류 문장과 단계만 문의합니다.

## 11. 안전 수칙 한 쪽
학생 실명·연락처는 입력하지 않고 번호로 바꿉니다. 학생 폴더·로그인 파일을 AI가 열지 않게 합니다. 비밀번호·인증 코드를 누구에게도 주지 않습니다. 원본·_original·백업은 편집하지 않습니다. 지문·문학·인용 원문을 임의로 바꾸지 않습니다. AI 그림에 넣을 한글은 나중에 별도 글자로 얹고 음원·이미지 권리를 확인합니다. 결과는 열어서 확인한 뒤 완료로 봅니다. 발송·게시·결제는 사람이 직접 합니다. 승인 내용을 모르면 거절합니다.

## 12. 내 업무 실행법 한 쪽
이 부분을 고객 작업실의 `내 업무 실행법.md`에 복사해 채웁니다.
- 선택 업무 A~E 하나: ___
- 입력: ___ (실명·연락처 제거 완료: ___)
- 실행 명령 한 줄: `/ek-workroom:<고른 스킬> <목표와 입력>`
- 생성할 새 결과 이름·위치: ___
- 미리보기 확인과 원장 승인: ___
- 사람 검수: 날짜/대상/근거/누락/쪽수·잘림 ___
- 원본 보존: ___ / 실패 시 멈출 단계: ___
- 처음 ___분 / 혼자 다시 ___분 / 수정 ___회 / 결과 열람 ___
수납·자동 게시 등 선택 업무 밖 일은 추가하지 않습니다. 도구가 없으면 수동 대안과 미완료 결과를 구분합니다.

## 13. 도움 요청
설정 변경 없이 `ek-diag`를 다시 실행해 `ek-diag.txt`를 만듭니다. 예: Windows `& "<플러그인>/scripts/ek-diag.ps1" -TargetHome "<고객 홈>" -DryRun`, Mac `bash "<플러그인>/scripts/ek-diag.sh" --home "<고객 홈>" --dry-run`. 진단은 읽기 전용으로 환경을 확인하고 텍스트 파일은 생성합니다. 실행 전에 수집 항목을 읽고 승인합니다.
내용을 직접 읽고 이름·이메일·전화번호·IP·홈 경로·파일 내용·목록이 없는지 확인합니다. 고객이 마스킹된 결과와 오류 한 줄, 마지막 성공 단계만 메신저로 직접 보냅니다. 화면·프로필·설정 원본을 판매자 AI에 보내지 않습니다. 지원은 시작일부터 30일, 영업일 1회 회신(성수기 2영업일), 2주 뒤 1시간 점검이며 날짜는 내 PC 설명서에 적습니다.
