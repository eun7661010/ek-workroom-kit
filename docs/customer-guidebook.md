# 내 AI 작업실 사용 설명서 v0.2.2

원장님 PC에 개통한 AI 작업실의 사용 설명서입니다. 무엇을 할 수 있는지, 매일 어떻게 쓰는지, 막히면 무엇을 하는지만 담았습니다. 원장님 본인 유료 계정으로 쓰고, 비밀번호와 인증 코드는 원장님만 입력합니다.

## 1. 이 작업실로 할 수 있는 일

| 하고 싶은 일 | 부르는 이름 | 결과 |
|---|---|---|
| 학습지·시험지를 깔끔한 A4 PDF로 | `worksheet-pdf` | 학생용 PDF와 정답용 PDF 따로 |
| 설명회·수업 슬라이드 | `lesson-slides` | 16:9 슬라이드 PDF와 발표자 메모 |
| 한글(HWPX) 파일 내용 꺼내기 | `hwpx-read` | 글자만 담긴 텍스트 파일 |
| 학부모 안내·상담 문자 | `parent-message` | 기본안, 짧은 문자안, 사실 확인표 |
| 명단·일정 표 대조 | `spreadsheet-check` | 대상 표와 틀린 곳 목록 |
| 맞춤법·띄어쓰기·문체 검수 | `korean-review` | 고칠 후보와 이유 |
| 문항 해설 초안 | `explanation-draft` | 정답 근거·오답 이유 초안 |
| 문항 초안 | `question-draft` | 문항과 검증표 |
| 블로그 글·원장 칼럼 | `blog-column` | 원장님 말투 원고 |
| **다른 AI에게 한 번 더 검사받기** | `cross-check` | Codex의 지적과 Claude의 판정, 고친 새 파일 |

### 이렇게 하면 좋은 점
- **두 AI가 서로 검사합니다.** Claude가 만들고, 회사가 다른 Codex가 읽기만 하면서 검사합니다. Claude는 지적마다 맞는지 따져서 맞는 것만 고칩니다. 한 AI만 쓸 때보다 날짜·숫자·근거 실수를 더 잘 잡습니다.
- **조판 프로그램을 따로 사지 않아도 됩니다.** Windows에 기본으로 있는 Edge 브라우저로 PDF를 만듭니다. 머리글·바닥글 없이 A4에 맞춰 나오고, 몇 쪽이 나왔는지도 알려 줍니다.
- **학생 정보가 지켜집니다.** 지정한 학생 폴더는 Claude가 읽지도 고치지도 못하게 막아 두었습니다.
- **원본이 지켜집니다.** 결과는 항상 새 파일로 만듭니다. 같은 이름 파일이 있으면 만들지 않습니다.
- **무엇이 도는지 보입니다.** 화면 아래에 지금 모델, 작업 폴더, 대화가 얼마나 찼는지 나옵니다. 5시간 사용량은 Claude가 유효한 값을 제공할 때만 나옵니다. 표시가 없어도 설정 실패는 아닙니다.
- **AI가 마음대로 하지 않습니다.** 파일 만들기·명령 실행 전에 항상 계획을 보여 주고 원장님 승인을 받습니다. 문자·메일·게시는 초안까지만 만들고, 보내는 것은 원장님이 합니다.

## 2. 매일 쓰는 법 (3단계)

1. **작업실 열기:** 기본 위치를 쓰시면 터미널(Windows Terminal 또는 PowerShell)에서 `cd "$HOME\AI작업실"`을 입력합니다. Mac은 `cd ~/AI작업실`입니다. 위치를 바꾸셨다면 개통 때 기록한 실제 작업실 절대 경로로 이동해 주세요.
2. **Claude 시작:** `claude`를 입력합니다.
3. **일 시키기:** `/ek-workroom:` 다음에 위 표의 이름을 쓰고, 이어서 할 일을 적습니다.

```text
/ek-workroom:worksheet-pdf ./입력/3월-비문학.txt로 학생용·정답용 학습지를 만들어 ./결과/에 저장할 계획을 먼저 보여 주세요
```

입력 자료는 `입력/`에 넣고, 결과는 `결과/`에서 엽니다. 손대면 안 되는 원본은 `원본/`에 둡니다.

| 폴더·파일 | 용도 |
|---|---|
| `입력/` | AI에게 줄 자료(실명·연락처 지운 것) |
| `결과/` | AI가 만든 결과 |
| `원본/` | 보관용 원본. AI가 고치지 않음 |
| `검토/` | Codex 검토 요청과 결과 |
| `내-업무-실행법.md` | 개통 날 만든 내 업무의 실행 한 줄 |
| `AGENTS.md` | Claude가 읽는 작업실 규칙 |

키트의 Codex 교차 검토는 빈 임시 폴더에서 실행됩니다. 검토 요청서와 지정한 파일 내용만 전달받습니다. Codex가 따라야 할 작업실 규칙은 검토 요청서에 적어 주세요.

Claude 안에서 자주 쓰는 것: `Esc` 멈추기, `/clear` 새 주제 시작, `/resume` 지난 대화 이어 하기, `/status` 로그인 계정 확인.

## 3. 조판: 학습지·슬라이드 PDF

- **학습지:** 원문 텍스트, 학년·제목, 문제와 정답을 `입력/`에 넣고 `worksheet-pdf`를 부릅니다. Claude가 학생용·정답용 HTML을 만든 뒤 Edge로 PDF를 만듭니다. 문항이 쪽 중간에서 잘리지 않게 하고, 원문은 바꾸지 않습니다.
- **슬라이드:** 청중, 발표 시간, 핵심 주장 세 개를 적고 `lesson-slides`를 부릅니다. 한 장에 메시지 하나로 만듭니다.
- **확인할 것:** 결과 PDF를 전 쪽 열어 글자 깨짐·넘침·빈 쪽, 그리고 학생용에 정답이 보이지 않는지 확인합니다.
- **PDF는 작업실 안에서만:** 작업실(`AI작업실`) 안의 HTML만 PDF로 만듭니다. 다른 폴더의 HTML은 작업실 `결과/`로 복사한 뒤 하세요.
- **그림·로고:** 그림 파일은 HTML과 같은 폴더(또는 그 아래)에 두고 이름으로만 넣습니다. PDF를 만들 때 키트는 그 폴더 하나만 브라우저에 보여 주고 인터넷도 끊습니다. 그래서 다른 폴더의 파일이나 인터넷 그림은 PDF에 들어가지 않고 빈칸으로 나옵니다. 학생 폴더 같은 다른 곳의 파일이 섞여 들어가는 일을 막기 위해서입니다.
- **Edge가 없을 때:** HTML 파일을 브라우저로 열고 인쇄 → "PDF로 저장"을 고릅니다. 머리글·바닥글은 끕니다.

## 4. 한글 파일 읽기

- `.hwpx` 파일은 `hwpx-read`로 글자를 꺼내 텍스트 파일로 저장합니다. 표·그림·수식은 빠질 수 있으니 원본과 비교합니다.
- `.hwp`(옛 형식)는 바로 읽지 못합니다. 한컴오피스에서 "다른 이름으로 저장 → HWPX"로 바꾼 뒤 다시 하세요.

## 5. 두 AI 교차 검토 (`cross-check`)

검토할 수 있는 파일은 MD·TXT·HTML·HTM·CSV입니다. PDF는 생성에 사용한 HTML을, HWPX는 추출한 TXT를 골라 주세요. UTF-8로 저장해 주세요. 파일당 200KB, 검토 대상 합계 500KB 이하입니다.

1. 검토할 파일을 고른 뒤 `/ek-workroom:cross-check ./결과/학습지.html 날짜·근거·누락을 검토받아 주세요`처럼 요청합니다.
2. Claude가 `검토/`에 검토 요청서를 쓰고, Codex를 **읽기 전용**으로 실행합니다. Codex는 파일을 고치지 못하고 의견만 `검토/`에 새 파일로 남깁니다.
3. Claude가 지적마다 "맞음/틀림/부분"과 근거를 보여 줍니다.
4. 원장님이 승인한 것만 반영한 **새 파일**을 만듭니다.

**학생 정보는 이렇게 지킵니다:** Codex는 파일을 직접 열거나 명령을 실행하거나 인터넷에 접속할 수 없는 상태로 실행됩니다. 키트가 작업실 안에서 원장님이 고른 결과 파일의 내용만 골라 넘깁니다. 학생 폴더 안의 파일은 넘기지 않습니다. 그래도 학생 실명이 든 파일은 검토 대상으로 고르지 마세요.

"Codex에게 다른 안 받기"라고 하면 Codex의 대안 초안을 `검토/`에 받아 비교할 수도 있습니다. Codex 사용량은 원장님 ChatGPT 요금제에서 나갑니다.

## 6. 화면 읽는 법

**상태줄** (화면 아래): `Opus 5.5 · AI작업실 · 대화 12% · 5시간 23%`
- 대화 %가 70%를 넘으면 `/compact`로 정리하거나 `/clear`로 새로 시작합니다.
- 5시간 %가 90%를 넘으면 큰 작업은 한도가 초기화된 뒤에 합니다.

5시간 사용량은 Claude가 유효한 값을 제공할 때만 표시됩니다. 표시가 없어도 설정 실패는 아닙니다.

**승인 창**: 명령 실행·인터넷 조회 때마다 승인을 묻습니다. 이렇게 판단합니다.

| 승인해도 되는 것 | 거절할 것 |
|---|---|
| `ek-workroom` 폴더의 스크립트(ek-pdf, ek-hwpx-text, ek-codex-review)를 작업실 파일에 실행 | **학생 폴더 경로가 보이는 명령** |
| 작업실 안에 새 파일·폴더 만들기 | 삭제·이동, `git push`, 모르는 프로그램 설치 |
| 버전 확인(`--version`) | 문자·메일 발송, 외부 사이트로 파일 보내기 |

학생 폴더 차단은 Claude의 규칙입니다. Windows 자체의 잠금은 아닙니다. 그래서 승인 창에 학생 폴더 경로가 보이면 반드시 거절합니다.

## 7. 안전 수칙

- 학생 실명·연락처는 입력하지 않고 번호로 바꿉니다.
- 비밀번호·인증 코드는 누구에게도 주지 않습니다. 판매자에게도 주지 않습니다.
- 지문·문학·인용 원문은 AI가 바꾸지 않게 합니다.
- 결과는 열어서 확인한 뒤 씁니다. 발송·게시·결제는 원장님이 직접 합니다.
- 모르는 승인 창은 거절하고 물어봅니다.

## 8. 자주 막히는 일

| 증상 | 먼저 할 일 |
|---|---|
| `claude`나 `codex`를 못 찾음 | 터미널을 닫고 새로 연 뒤 다시 입력 |
| 로그인 브라우저가 안 열림 | Claude: 화면에서 `c`로 주소 복사 → 브라우저에 붙여 로그인 → 나온 코드를 Claude 화면에 붙여넣기. Codex: `codex login --device-auth` |
| 로그인 만료 | 본인이 다시 로그인 |
| `/ek-workroom:` 목록이 안 보임 | Claude를 껐다 켜고 `/plugin`에서 ek-workroom이 켜져 있는지 확인 |
| 상태줄이 안 보임 | Claude를 껐다 켜기 |
| PDF가 안 만들어짐 | HTML 파일을 브라우저로 열어 인쇄 → PDF로 저장 |
| PDF 글자 잘림·빈 쪽 | Claude에게 "몇 쪽 어디가 잘렸다"고 말하고 새 이름으로 다시 만들기 |
| "같은 이름 파일이 있음" | 정상입니다. 새 이름을 정해 주세요 |
| 교차 검토가 안 됨 | 새 터미널에서 `codex`로 로그인 확인. 안 되면 Claude 혼자 검수로 진행 |
| 한도 초과 | 상태줄에 5시간 %가 있으면 확인하고, 없으면 Claude의 한도 안내를 확인해 초기화 뒤 다시 |

같은 오류가 세 번 나면 멈추고 9절대로 문의합니다.

## 9. 도움 요청

1. 진단 파일을 새로 만듭니다(설정을 바꾸지 않습니다). Claude에게 "ek-diag 진단을 다시 만들어 주세요"라고 하면 계획을 보여 주고 승인 뒤 `~/ek-diag.txt`를 만듭니다.
2. 파일을 직접 열어 이름·이메일·전화번호·파일 내용이 없는지 확인합니다.
3. 진단 내용, 오류 문장 한 줄, 마지막으로 성공한 단계를 메신저로 보냅니다.

지원은 개통일부터 30일이고, 영업일 1회 답장합니다(성수기 2영업일). 2주 뒤 1시간 점검이 있습니다. 날짜는 `내-업무-실행법.md` 아래에 적어 둡니다.

## 10. 업데이트와 되돌리기

- Claude Code는 공식 자동 업데이트로 최신 버전을 유지합니다. 키트(플러그인) 업데이트는 판매자가 새 붙여넣기 블록을 보내 드릴 때만 합니다.
- 업데이트 뒤 확인: `claude --version`, `/ek-workroom:` 목록, 상태줄, 학습지 PDF 한 번.
- 설정을 원래대로 돌리려면 판매자에게 요청합니다. 키트가 바꾼 것과 되돌리는 법은 `install-checklist.md` 4절과 10절에 모두 적혀 있습니다.
