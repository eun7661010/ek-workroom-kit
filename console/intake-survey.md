# 사전 설문과 고객 로컬 프로필 v0.2.0
이름·이메일·전화번호·학생 자료를 받지 않습니다. 연락·계약은 기존 고객관리에서 처리합니다. 학생 폴더 경로는 고객이 자기 PC 프로필에만 적으며 프로필 원본을 판매자 AI에 전달하지 않습니다.

| 질문 | 답 형식 | 프로필 대응 |
|---|---|---|
| 오늘 끝낼 업무는? | A 상담/안내문, B 공지+대상 CSV, C 주간 보고, D 블로그 원고, E 학습지 HTML/PDF 중 하나 | workflow.code와 같은 글자의 template |
| Windows인가요 Mac인가요? | windows / macos | os |
| 본인 Claude·Codex 구독과 로그인을 확인했나요? | 고객 화면에서 사용 가능 여부만 확인 | 저장하지 않음 |
| 보안 프로그램과 관리 PC 여부는? | 프로그램 이름 배열, 관리 정책 별도 메모 | securitySoftware |
| 학생정보 폴더는? 판매자에게 말하지 말고 로컬에 적어 주세요 | 와일드카드 없는 절대 경로 | studentDataPaths |
| 비식별 작업실 위치는? | 생략하면 고객 홈/AI작업실, 학생 폴더와 겹치지 않는 절대 경로 | workspacePath 선택 |

schemaVersion은 데이터 형식 `0.1`을 유지합니다. `plugins/ek-workroom/profiles/example.json`을 로컬에 복사합니다. 비밀번호·인증 코드·API 키·실명을 넣지 않습니다. 스킬은 진행용 6개·고객용 10개가 함께 설치됩니다.

- 중요 원본 백업과 개인정보를 지운 샘플 3~5개가 있나요?
- 표는 엑셀에서 CSV UTF-8로 저장했나요?
- 학생 폴더·메신저·메일을 닫고 작업 창만 공유할 수 있나요?
- 로그인·휴대폰 인증은 공유를 끄고 직접 할 수 있나요?
- 연속 165분, 안정적인 인터넷이 준비됐나요?
- 보안 정책으로 설치가 막히면 PC 관리자와 연락할 수 있나요?
- 부트스트랩의 두 CLI 설치 결과를 확인했나요? 런타임 추가 설치는 하지 않습니다.
