# 주간 수업 보고 초안

## 기준 정보
| 항목 | 내용 |
| --- | --- |
| 학원·과목 | [입력] |
| 주차·기간 | [연도 포함/확인 필요] |
| CSV 검수 보고서 | [작업실 내 경로] |
| 입력 행 수·대상 반 수 | [입력] |
| 발송 상태 | [발송 보류/수동 발송 준비] |

## 반별 4문장 보고
### [반번호] · [주차]
이번 주에는 [제공된 진도]를 다루었습니다.
과제는 [제공된 과제]입니다.
다음 수업에서는 [제공된 다음 계획]을 진행합니다.
가정에서는 [제공된 협조 요청/과제 범위를 함께 확인해 주세요].

[위 블록을 반별로 반복한다. 진도·과제·계획이 없으면 확인 필요로 표시하고 해당 반 발송을 보류한다. 학생 태도·수행률·성적은 추측하지 않는다.]

## 누락 확인표
| 반번호·주차 | 입력 행 | 누락·중복·충돌 | 처리 |
| --- | --- | --- | --- |
| [익명 반·주차] | [행 번호] | [없음/구체 항목] | [작성/보류] |

## 수동 발송 전 확인
- [ ] 반·주차별로 내용이 섞이지 않고 진도·과제가 원자료와 같다.
- [ ] 수행·태도·성적을 추측하지 않았고 누락 반을 보류했다.
- [ ] 원장이 파일을 열어 읽고 수동 발송 대상을 확인했다.
