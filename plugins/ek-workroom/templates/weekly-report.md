| 항목 | 내용 |
| --- | --- |
| 학원·과목 | [입력] |
| 주차·기간 | [연도 포함/확인 필요] |
| CSV 검수 보고서 | [작업실 내 경로] |
| 입력 행 수·대상 반 수 | [입력] |

## 반별 4문장 보고
### [반번호] · [과목] · [보고 기간: 연도·시작일~종료일]
이번 주에는 [제공된 진도]를 다루었습니다.
과제는 [제공된 교재명·범위]이며 제출 기한은 [제공된 날짜·시간]입니다.
다음 수업에서는 [제공된 다음 계획]을 진행합니다.
가정에서는 [제공된 협조 요청/과제 범위를 함께 확인해 주세요].

[위 블록을 반별로 반복한다. 과목·정확한 기간·진도·교재명·과제 범위·제출 기한·계획이 없으면 확인 필요로 표시하고 해당 반 발송을 보류한다. 학생 태도·수행률·성적은 추측하지 않는다.]

## 누락 확인표
예상 대상 반 목록: [작업실 내 경로/미제공]. 목록 미제공 시 ‘입력된 행의 빈칸·중복만 검사했으며 전체 반 누락은 미확인’으로 표시한다.
| 반번호·과목·보고 기간(필요 시 수업 일시) | 입력 행 | 누락·중복·충돌 | 처리 |

## 수동 발송 전 확인
- [ ] 반·과목·보고 기간별로 내용이 섞이지 않고 진도·과제가 원자료와 같다.
- [ ] 수행·태도·성적을 추측하지 않았고 누락 반을 보류했다.
- [ ] 원장이 파일을 열어 읽고 수동 발송 대상을 확인했다.
