# 업무 E: 학습지 HTML→PDF
판매자가 D-7에 이 시안을 고객 조건에 맞게 준비합니다. 개인정보 없는 더미로 검수한 뒤에만 고객이 직접 비식별 실제 샘플을 넣습니다. 프로그램 설치·자동 발송·발행은 하지 않습니다.

## 더미 입력
```text
제목: 근거 찾기 연습(더미)
자체 작성 원문: 비가 오는 날에는 운동장을 쓰지 않는다. 오늘은 비가 온다.
문제 1: 오늘 운동장을 쓰는지와 그 근거를 쓰세요.
정답: 쓰지 않는다. 조건과 오늘의 사실이 모두 해당한다.
```

## 실행 한 줄
원장님이 위 더미 입력 또는 새 비식별 샘플을 작업실의 `./입력/E-입력.txt`에 직접 저장합니다. 입력이 없으면 파일 탐색 없이 멈추고 정확한 위치를 확인합니다. `새번호`는 기존 결과와 겹치지 않는 번호로 바꿉니다.
`/ek-workroom:worksheet-pdf ./입력/E-입력.txt만 읽고 업무 E의 학생용·정답용 A4 HTML과 PDF를 ./결과/E-학생용-새번호.html/.pdf, ./결과/E-정답용-새번호.html/.pdf에 만들 계획을 보여 주세요. 승인 후 새 HTML 두 개를 만들고 ek-pdf로 각각 PDF까지 생성해 모든 쪽을 열어 확인해 주세요.`

## 결과와 검수
- 결과: 학생용/정답용 HTML과 인쇄 PDF
- 검수: 원문 보존·학생용 정답 분리·A4 잘림·글자 깨짐·쪽수
- 변경 계획과 새 파일 이름을 먼저 보여 주고 원장 승인 뒤 생성합니다. 기존 파일과 원본은 덮어쓰지 않습니다.

## 실제 샘플로 바꾸기
원장님이 실명·연락처·이메일을 제거한 샘플을 이 입력 형태로 준비합니다. 학생 폴더를 AI가 열지 않습니다. 고객 본인 Claude만 처리하며 판매자 AI에 전달하지 않습니다.

## 단독 재실행 기록
입력 위치: ./입력/E-입력.txt / 실행 명령: 위 경로를 넣은 한 줄 / 결과 위치: ./결과/E-학생용-새번호.html/.pdf 및 E-정답용-새번호.html/.pdf / 사람 검수: 위 검수 항목
첫 실행 ___분 / 단독 재실행 ___분 / 수정 ___회 / 원장 결과 열람 ___ / 미완료 ___

## 도구가 없을 때
텍스트·HTML 또는 기존 프로그램의 수동 기능까지 제공합니다. worksheet-pdf가 ${CLAUDE_PLUGIN_ROOT}/scripts/ek-pdf.ps1 또는 ek-pdf.sh를 호출합니다. 필요한 도구를 자동 설치하지 않으며 PDF가 안 되면 미완료로 표시합니다.
