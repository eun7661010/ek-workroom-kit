# 업무 B: 휴강·보강 공지와 대상 표
판매자가 D-7에 이 시안을 고객 조건에 맞게 준비합니다. 개인정보 없는 더미로 검수한 뒤에만 고객이 직접 비식별 실제 샘플을 넣습니다. 프로그램 설치·자동 발송·발행은 하지 않습니다.

## 더미 입력
```text
반번호,기존수업,변경수업,변경유형,장소,사유,비용,문의
C01,2026-11-03 화요일 18:00~19:00,2026-11-05 목요일 18:00~19:00,보강,1강의실,학교 행사,추가 비용 없음,기존 학원 상담 채널
C02,2026-11-04 수요일 17:00~18:00,변경 없음,없음,1강의실,해당 없음,추가 비용 없음,기존 학원 상담 채널
```

## 실행 한 줄
양식은 `${CLAUDE_PLUGIN_ROOT}/templates/`에서 찾습니다. 아래 `templates/`는 이 절대 경로를 뜻합니다.
원장님이 위 더미 입력 또는 새 비식별 샘플을 작업실의 `./입력/B-입력.csv`에 CSV UTF-8로 직접 저장합니다. 엑셀 원본은 엑셀에서 CSV UTF-8로 저장합니다. 입력이 없으면 파일 탐색 없이 멈추고 정확한 위치를 확인합니다. `새번호`는 기존 결과와 겹치지 않는 번호로 바꿉니다.
`/ek-workroom:parent-message ./입력/B-입력.csv만 읽고 templates/notice-table.md를 복사해 ./결과/B-초안-새번호.md에 공지문·변경 대상 표·제외표를 만들 계획을 먼저 보여 주세요. 원장 승인 후 새 파일로 생성하고 열어 변경 없는 반 제외·중복·일정을 확인해 주세요. 미확정 반은 발송 보류로 남겨 주세요.`

## 결과와 검수
- 결과: 공지문과 반번호별 변경 대상 표
- 검수: 변경 없는 반 제외·중복 반·휴강/보강 관계·발송은 수동
- 변경 계획과 새 파일 이름을 먼저 보여 주고 원장 승인 뒤 생성합니다. 기존 파일과 원본은 덮어쓰지 않습니다.

## 실제 샘플로 바꾸기
원장님이 실명·연락처·이메일을 제거한 샘플을 이 입력 형태로 준비합니다. 학생 폴더를 AI가 열지 않습니다. 고객 본인 Claude만 처리하며 판매자 AI에 전달하지 않습니다.

## 단독 재실행 기록

첫 실행 ___분 / 단독 재실행 ___분 / 수정 ___회 / 원장 결과 열람 ___ / 미완료 ___

## 도구가 없을 때
텍스트·HTML 또는 기존 프로그램의 수동 기능까지 제공합니다. 필요한 도구를 자동 설치하지 않으며 PDF·편집본 생성이 안 되면 해당 결과를 미완료로 표시합니다.
