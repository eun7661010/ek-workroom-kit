# 업무 C: 주간 수업 보고
판매자가 D-7에 이 시안을 고객 조건에 맞게 준비합니다. 개인정보 없는 더미로 검수한 뒤에만 고객이 직접 비식별 실제 샘플을 넣습니다. 프로그램 설치·자동 발송·발행은 하지 않습니다.

## 더미 입력
```text
반번호,주차,진도,과제,제출기한,다음계획,과목,기간
C01,1주,일차방정식 1단원,가상 워크북 3~4쪽,2026-11-09 18:00,등식 성질 복습,수학,2026-11-02~2026-11-08
C02,1주,문자와 식 2단원,가상 연습장 1~3번,2026-11-09 18:00,대입 연습,수학,2026-11-02~2026-11-08
```

## 실행 한 줄
예상 대상 반 목록도 원장이 작업실에 준비해 경로를 지정합니다. 입력 반과 목록을 대조해 행 자체가 빠진 반을 확인합니다. 더미 예상 반은 C01·C02입니다. 목록이 없으면 “입력된 행의 빈칸·중복만 검사했으며 전체 반 누락은 미확인”으로 표시합니다.
양식은 `${CLAUDE_PLUGIN_ROOT}/templates/`에서 찾습니다. 아래 `templates/`는 이 절대 경로를 뜻합니다.
원장님이 위 더미 입력 또는 새 비식별 샘플을 작업실의 `./입력/C-입력.csv`에 CSV UTF-8로 직접 저장합니다. 엑셀 원본은 엑셀에서 CSV UTF-8로 저장합니다. 입력이 없으면 파일 탐색 없이 멈추고 정확한 위치를 확인합니다. `새번호`는 기존 결과와 겹치지 않는 번호로 바꿉니다.
`/ek-workroom:spreadsheet-check ./입력/C-입력.csv와 지정된 예상 대상 반 목록만 읽고 반번호+과목+보고 기간을 기본 키로(수업별 여러 행이면 수업 일시도 포함) 중복·누락·행 수를 검사해 ./결과/C-검수-새번호.md에 보고할 계획과 /ek-workroom:parent-message가 templates/weekly-report.md를 복사해 ./결과/C-초안-새번호.md에 반별 4문장 보고를 만들 계획을 함께 보여 주세요. 원장 승인 후 보고서만 생성하고 CSV는 수정하지 마세요. 두 결과를 열어 확인하고 누락·중복 반은 발송 보류로 남겨 주세요.`

## 결과와 검수
- 결과: 반별 4문장 보고서와 누락 확인표
- 검수: 반별 혼합 없음·진도/과제 원문 일치·학생 평가 추측 없음
- 변경 계획과 새 파일 이름을 먼저 보여 주고 원장 승인 뒤 생성합니다. 기존 파일과 원본은 덮어쓰지 않습니다.

## 실제 샘플로 바꾸기
원장님이 실명·연락처·이메일을 제거한 샘플을 이 입력 형태로 준비합니다. 학생 폴더를 AI가 열지 않습니다. 고객 본인 Claude만 처리하며 판매자 AI에 전달하지 않습니다.

## 단독 재실행 기록

## 도구가 없을 때
텍스트·HTML 또는 기존 프로그램의 수동 기능까지 제공합니다. 필요한 도구를 자동 설치하지 않으며 PDF·편집본 생성이 안 되면 해당 결과를 미완료로 표시합니다.
