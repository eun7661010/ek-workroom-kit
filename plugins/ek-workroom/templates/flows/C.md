# 업무 C: 주간 수업 보고
판매자가 D-7에 이 시안을 고객 조건에 맞게 준비합니다. 개인정보 없는 더미로 검수한 뒤에만 고객이 직접 비식별 실제 샘플을 넣습니다. 프로그램 설치·자동 발송·발행은 하지 않습니다.

## 더미 입력
```text
반번호,주차,진도,과제,다음계획
C01,1주,독서 구조 1단원,워크북 3~4쪽,문장 관계 복습
C02,1주,문학 화자 2단원,연습 1~3번,근거 찾기
```

## 실행 한 줄
`/ek-workroom:spreadsheet-check 위 더미 입력으로 업무 C의 초안을 만들고, 사실이 부족한 부분은 확인 필요로 표시해 주세요.`

## 결과와 검수
- 결과: 반별 4문장 보고서와 누락 확인표
- 검수: 반별 혼합 없음·진도/과제 원문 일치·학생 평가 추측 없음
- 변경 계획과 새 파일 이름을 먼저 보여 주고 원장 승인 뒤 생성합니다. 기존 파일과 원본은 덮어쓰지 않습니다.

## 실제 샘플로 바꾸기
원장님이 실명·연락처·이메일을 제거한 샘플을 이 입력 형태로 준비합니다. 학생 폴더를 AI가 열지 않습니다. 고객 본인 Claude만 처리하며 판매자 AI에 전달하지 않습니다.
