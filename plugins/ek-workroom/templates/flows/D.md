# 업무 D: 원장 문체 블로그 초안
판매자가 D-7에 이 시안을 고객 조건에 맞게 준비합니다. 개인정보 없는 더미로 검수한 뒤에만 고객이 직접 비식별 실제 샘플을 넣습니다. 프로그램 설치·자동 발송·발행은 하지 않습니다.

## 더미 입력
```text
주제: 숙제 양보다 점검 습관이 중요한 이유
독자: 중학생 학부모
주장: 틀린 이유를 한 줄 쓰는 습관
예시: 가상의 연습 문제 오답 기록
길이: 800자
문체: 차분한 존댓말
```

## 실행 한 줄
양식은 `${CLAUDE_PLUGIN_ROOT}/templates/`에서 찾습니다. 아래 `templates/`는 이 절대 경로를 뜻합니다.
원장님이 위 더미 입력 또는 새 비식별 샘플을 작업실의 `./입력/D-입력.txt`에 직접 저장합니다. 입력이 없으면 파일 탐색 없이 멈추고 정확한 위치를 확인합니다. `새번호`는 기존 결과와 겹치지 않는 번호로 바꿉니다.
`/ek-workroom:blog-column ./입력/D-입력.txt만 읽고 제목 3개·주장·근거·가상 예시 개요와 ./결과/D-초안-새번호.md 및 ./결과/D-검수-새번호.md 생성 계획을 먼저 보여 주세요. 원장 승인 후 새 파일로 생성하고 두 결과를 열어 사실·문체·분량을 확인해 주세요. 자동 게시하지 마세요.`

## 결과와 검수
- 결과: 제목 3개와 본문, 선택 시 복사용 HTML
- 검수: 실제 사례로 오인될 표현·근거 없는 통계·자동 발행 없음
- 변경 계획과 새 파일 이름을 먼저 보여 주고 원장 승인 뒤 생성합니다. 기존 파일과 원본은 덮어쓰지 않습니다.

## 실제 샘플로 바꾸기
원장님이 실명·연락처·이메일을 제거한 샘플을 이 입력 형태로 준비합니다. 학생 폴더를 AI가 열지 않습니다. 고객 본인 Claude만 처리하며 판매자 AI에 전달하지 않습니다.

## 단독 재실행 기록
입력 위치: ./입력/D-입력.txt / 실행 명령: 위 경로를 넣은 한 줄 / 결과 위치: ./결과/D-초안-새번호.md 및 D-검수-새번호.md / 사람 검수: 위 검수 항목
첫 실행 ___분 / 단독 재실행 ___분 / 수정 ___회 / 원장 결과 열람 ___ / 미완료 ___

## 도구가 없을 때
텍스트·HTML 또는 기존 프로그램의 수동 기능까지 제공합니다. 필요한 도구를 자동 설치하지 않으며 PDF·편집본 생성이 안 되면 해당 결과를 미완료로 표시합니다.
