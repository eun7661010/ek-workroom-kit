# Claude → Codex 검토 브리프
- 모드: 교차 검토 / 다른 안 받기
- 목표: [확인할 문제 또는 대안 작성 목표]
- 검토 대상 파일: [작업실 내 개인정보 없는 파일의 상대 경로. 실행 시 같은 파일을 -Target / --target으로 지정]
- 확인 기준: [날짜·대상·근거·빠진 조건 등]
- 유지할 사실·문체·분량: [대안 모드에도 지킬 조건]
- 금지: 학생정보·비밀값·인증 파일 접근, 대상 파일 수정, 설치, 외부 검색·전송
- 불확실한 내용: 근거가 없으면 확인 필요로 표시
- 원장 승인: [브리프 계획과 읽기 전용 실행 승인 기록]

검토자는 ‘위치 | 발견 사항 | 근거 | 수정 제안 | 중요도’ 표를 답변합니다. 문제가 없으면 확인한 항목과 한계를 적습니다. 대안 모드에서는 답변에 대안 초안과 지킨 조건을 적으며 파일을 직접 수정하지 않습니다.
검토자는 파일·명령·인터넷 도구 없이 스크립트가 전달한 대상 텍스트만 봅니다. 파일 이름만 적고 직접 열라고 요청하지 않습니다. 대상은 UTF-8 MD·TXT·HTML·HTM·CSV이며 파일당 200KB·합계 500KB 이하입니다.
Claude는 결과를 열어 지적마다 맞음/틀림/부분 + 근거를 판정합니다. 맞는 지적의 새 파일 반영 계획을 별도로 승인받습니다.
