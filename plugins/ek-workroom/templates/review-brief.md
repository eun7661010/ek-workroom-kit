# Claude → Codex 검토 브리프
- 목표: [안내문 날짜·대상·과장 표현 확인 등]
- 입력: [이 작업실의 개인정보 없는 초안 한 개와 근거 표]
- 금지: 파일 수정, 설치, 전송, 학생정보·인증 파일 접근, 외부 검색
- 완료 기준: 사실 오류/누락/개인정보 가능성을 구분해 위치·이유·수정 제안 반환
- 불확실한 내용: [근거가 없으면 확인 필요로 표시]
- 원장 승인: [검토 범위와 읽기 전용 실행 승인 여부]

검토자는 ‘위치 | 발견 사항 | 근거 | 수정 제안 | 중요도’ 표를 반환합니다. 문제가 없으면 확인한 항목과 한계도 적습니다. Claude는 원문과 대조하고 원장님이 최종 검수합니다.
