# 국어 문항·변형문제 초안과 검증표를 설계할 때 사용한다.

## 기본 원칙
고객이 직접 개인정보를 제거한 입력만 사용합니다. 학생정보 폴더·계정 파일은 열지 않습니다. 원본·인용·문학 원문은 보호합니다. 변경 파일과 내용을 먼저 보여 주고 승인 후 생성하며 기존 원본을 덮어쓰지 않습니다. 외부 검색·외부 전송·게시·발송·프로그램 설치는 하지 않습니다. 비밀번호·인증 코드를 묻지 않습니다. 필수 도구가 없으면 설치하지 않고 아래 수동 대안과 미완료 범위를 알립니다.

## 입력과 순서
1. 국어 전용입니다. 사용 권리가 있는 지문, 학습 목표, 문항 수, 난도, 정답 근거를 받습니다. 원문은 변경하지 않습니다.
2. 한 문항은 한 판단 목표를 갖게 하고 발문을 먼저 정합니다. 정답 근거 문장과 필요한 추론을 먼저 쓰고 정답 선지를 만듭니다.
3. 오답은 범위 확대/주체 바꿈/인과 역전/조건 누락 중 서로 다른 이유로 만듭니다. 단어 길이만으로 정답이 드러나지 않게 맞춥니다.
4. 모든 선지를 지문과 대조해 ‘정답 근거 있음·오답 반증 가능·복수 정답 없음·문장 모호함 없음’을 검사합니다. 근거가 부족하면 문항을 보류합니다.

## 출력·검수
문제지 초안과 정답·해설·선지별 검증표를 분리합니다. ‘공식 기출’로 표기하지 않고 AI 보조 초안임을 표시합니다. 다른 검토자 또는 원장이 모든 선지를 판정해야 배포할 수 있습니다.

## 도구가 없을 때
텍스트로 초안까지 제공합니다. 조판·PDF는 별도 업무이며 자동 배포하지 않습니다. 타 과목 문제 출제를 검증 완료로 주장하지 않습니다.
