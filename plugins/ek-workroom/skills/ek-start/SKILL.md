# AI 작업실 세션 시작과 사전 준비를 확인할 때 사용한다.

## 공통 약속
고객 본인 Claude Code에서 진행합니다. 판매자는 Zoom으로 감독하며 판매자 AI에는 고객이 읽고 붙여 넣은 마스킹 진단만 전달합니다. 비밀번호·인증 코드·API 키는 묻거나 저장하지 않습니다. 로그인은 고객이 직접 하고 화면 공유를 잠시 끕니다.
모든 변경은 먼저 DryRun으로 대상과 결과를 설명하고 원장 승인 뒤 적용합니다. 학생정보 폴더는 열거나 탐색하지 않습니다. 고객이 먼저 개인정보를 지운 샘플만 씁니다. 런북 밖 요청은 “세션 뒤 판매자와 상의해 주세요”로 돌립니다. 같은 오류가 3회면 멈춥니다. 결과를 확인하기 전 완료라고 말하지 않습니다.

## 단계
`<플러그인>`은 `${CLAUDE_PLUGIN_ROOT}`가 가리키는 설치된 플러그인의 절대 경로입니다. 이 변수는 Claude가 Markdown을 읽을 때 실제 경로로 치환합니다. 치환된 절대 경로를 따옴표로 감싸며 PowerShell에서 변수 문자를 직접 평가하지 않습니다. 현재 작업 폴더 기준으로 scripts/templates를 찾지 않습니다. `<고객 홈>`과 `<프로필 JSON>`은 원장님이 지정한 로컬 절대 경로로 바꿉니다.

1. 원장님이 지정한 프로필 JSON만 읽고 스키마와 대조합니다. `studentDataPaths`는 차단 설정용 문자열로만 다루고 그 경로를 열지 않습니다. 비밀값·실명·연락처가 있으면 지워 달라고 요청합니다.
2. D-1 진단을 원장님이 이미 읽었고 환경이 바뀌지 않았다면 수집을 반복하지 않고 해당 결과만 확인합니다. 진단이 없거나 환경이 바뀐 경우 Windows에서 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File "<플러그인>/scripts/ek-diag.ps1" -TargetHome "<고객 홈>" -DryRun`, Mac에서 `bash "<플러그인>/scripts/ek-diag.sh" --home "<고객 홈>" --dry-run`으로 실행할 계획을 설명합니다. 수집 항목(OS·도구 버전·PATH 개수·디스크 여유·실행 정책·보안 SW·도달 여부)을 먼저 보여 주고 승인 후 읽기 전용 진단을 수행합니다. 이 명령은 설정을 바꾸지 않지만 ek-diag.txt 파일은 생성합니다.
3. `ek-diag.txt`는 원장님이 직접 읽습니다. 원장님이 고른 마스킹 결과만 판매자에게 붙여 넣습니다. 프로필·설정 파일을 보내지 않습니다.
4. 고객 본인 유료 구독 로그인, 샘플 3~5개, 차단 폴더, 원본 백업, 업무 A~E 중 한 개를 확인합니다. 실제 계정은 고객이 `/status`로 확인합니다.
5. 시작 10~30분 구간에서 Codex 설치·본인 로그인을 먼저 확인합니다. 없으면 판매자가 준비한 공식 설치 파일의 실행 계획을 보여 주고 원장 승인 후 별도 프로세스로 실행합니다. Node/Python은 설치하지 않습니다. 설치했다면 새 터미널과 Claude를 다시 열어 `codex --version`을 확인합니다. 60~70분 `ek-codex-link`는 설치를 반복하지 않고 교차 검토만 합니다.
6. Claude 로그인 브라우저가 안 열리면 `c`로 표시된 URL을 복사해 직접 엽니다. 브라우저에 승인 코드가 나오면 판매자에게 주지 않고 본인 Claude 터미널의 `Paste code here if prompted`에 붙여 넣습니다. Codex가 브라우저 로그인에서 막히면 고객이 `codex login --device-auth`를 실행하고 표시된 공식 주소와 코드로 직접 인증합니다. 로그인 중 공유를 끕니다.
7. 시작·로그인 확인→안전→상태줄·스킬→Codex 검토→업무 1개→단독 재실행→종료, 165분 목표를 안내합니다.

## 확인 질문
“진단 내용을 직접 읽으셨나요? 오늘은 프로필의 업무 한 개로 진행해도 될까요?”

## 완료 확인
프로필·진단·본인 로그인·샘플·백업을 확인한 뒤 `/ek-workroom:ek-safety`로 이동합니다.

## 막힐 때 대처
진단에 개인정보가 보이면 전달을 멈추고 고객이 해당 줄을 지웁니다. 로그인 자체가 안 되면 고객이 계정 문제를 해결한 뒤 재예약합니다. Node/Python은 없어도 설치하지 않습니다.

## 하지 말 것
전체 홈 검색, 학생 폴더 열기, 환경변수 전체 출력, 인증 파일 읽기, 판매자 계정 로그인, 자동 전송을 하지 않습니다.
