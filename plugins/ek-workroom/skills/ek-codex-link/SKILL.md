# 고객 본인 Codex의 읽기 전용 교차 검토를 연결할 때 사용한다.

## 공통 약속
고객 본인 Claude Code에서 진행합니다. 판매자는 Zoom으로 감독하며 판매자 AI에는 고객이 읽고 붙여 넣은 마스킹 진단만 전달합니다. 비밀번호·인증 코드·API 키는 묻거나 저장하지 않습니다. 로그인은 고객이 직접 하고 화면 공유를 잠시 끕니다.
모든 변경은 먼저 DryRun으로 대상과 결과를 설명하고 원장 승인 뒤 적용합니다. 학생정보 폴더는 열거나 탐색하지 않습니다. 고객이 먼저 개인정보를 지운 샘플만 씁니다. 런북 밖 요청은 “세션 뒤 판매자와 상의해 주세요”로 돌립니다. 같은 오류가 3회면 멈춥니다. 결과를 확인하기 전 완료라고 말하지 않습니다.

## 단계
`<플러그인>`은 `${CLAUDE_PLUGIN_ROOT}`가 가리키는 설치된 플러그인의 절대 경로입니다. 이 변수는 Claude가 Markdown을 읽을 때 실제 경로로 치환합니다. 치환된 절대 경로를 따옴표로 감싸며 PowerShell에서 변수 문자를 직접 평가하지 않습니다. 현재 작업 폴더 기준으로 scripts/templates를 찾지 않습니다. `<고객 홈>`과 `<프로필 JSON>`은 원장님이 지정한 로컬 절대 경로로 바꿉니다.

1. `ek-start`의 시작 10~30분 구간에서 설치·로그인을 끝냈는지 확인합니다. 이 구간은 60~70분 교차 검토입니다. `codex --version`, `codex exec --help`로 확인하고 이미 설치했다면 반복하지 않습니다. 미설치라면 교차 검토를 보류하고 설치 구간으로 돌아갑니다. Windows 공식 설치 주소는 `https://chatgpt.com/codex/install.ps1`, Mac은 `https://chatgpt.com/codex/install.sh`입니다. 공식 파일을 다운로드해 별도 PowerShell/sh 프로세스로 실행할 계획을 보여 주고 원장 승인 후 고객이 실행합니다. 설치 후 새 터미널·Claude를 열어 PATH를 확인합니다. Node/Python은 설치하지 않습니다.
2. `codex`에서 “Sign in with ChatGPT”로 본인 유료 계정에 직접 로그인합니다. 브라우저 연결이 막히면 `codex login --device-auth`를 사용하고 고객이 표시된 공식 주소와 코드를 직접 입력합니다. 판매자는 로그인 화면을 보지 않습니다. 현재 요금제에서 Codex를 쓸 수 있는지 고객 화면에서 확인합니다.
3. `<플러그인>/templates/AGENTS.md`, `<플러그인>/templates/review-brief.md`를 개인정보 없는 고객 작업 폴더에 복사할 계획을 제시합니다. 기존 AGENTS.md가 있으면 별도 초안으로 비교하고 덮어쓰지 않습니다. 승인 뒤 복사하며 Codex 홈 설정은 쓰지 않습니다.
4. Claude가 비식별 초안과 브리프(목표·입력·금지·완료 기준)를 만듭니다. 도움말에서 지원을 확인한 뒤 그 작업실에서 `codex exec --skip-git-repo-check --sandbox read-only "<비밀값 없는 검토 요청>"`를 실행합니다. 읽기 전용은 모든 파일 읽기를 차단한다는 뜻이 아니므로 학생정보와 경로를 입력에 넣지 않습니다.
5. Claude가 검토 결과를 근거와 대조하고 타당한 지적만 수정합니다. 원장님이 최종 결과를 열어 확인합니다.
6. 계정 전환은 본인 소유·본인 결제 업무용↔개인용의 공식 로그아웃/로그인만 고객이 수행합니다. 자동 다계정 전환은 v0.1.1 범위 밖입니다. 실제 계정 확인 후 프로필의 accountLabel을 바꾸고 apply-statusline을 미리보기→승인→적용 순으로 다시 실행합니다. 별칭은 로그인 확인이 아닙니다.

## 확인 질문
“본인 계정이며, 이 비식별 초안만 읽기 전용으로 검토할까요?”

## 완료 확인
본인 로그인·템플릿·도움말 확인 후 더미 초안 한 건의 검토 결과와 수정 이유를 고객이 설명하면 완료입니다.

## 막힐 때 대처
로그인 실패는 고객이 계정 지원으로 해결합니다. 설치·인증이 안 되면 Claude 단독 검수로 임시 진행하고 Codex 연동 미완료로 인계합니다. 옵션이 다르면 실행을 멈추고 도움말에 맞는 계획을 다시 제시합니다.

## 하지 말 것
계정 공유, 판매자 대리 로그인, API 키 연결, 인증 파일 복사, 백그라운드 실행, 학생정보 파일 검토를 하지 않습니다.
