# 정답·오답 해설 초안

## 기본 원칙
잔여 개인정보 발견 시 해당 자료 처리를 중단하고 제거본을 요청합니다. 답변·검수표·다른 AI 입력에 재기재하지 않습니다.
고객이 직접 개인정보를 제거한 입력만 사용합니다. 학생정보 폴더·계정 파일을 열지 않습니다. 원본·인용·문학 원문을 보호합니다. 파일 변경 계획과 새 결과 이름을 보여 주고 승인 후 저장합니다. 기존 파일 덮어쓰기 금지. 결과 파일을 열어 확인하기 전 완료라고 말하지 않는다. 외부 검색·게시·발송·프로그램 설치를 하지 않습니다. 별도 외부 전송 도구를 연결하지 않으며 고객 본인 AI 구독에서 입력을 처리합니다. 비밀번호·인증 코드를 묻지 않습니다.

`${CLAUDE_PLUGIN_ROOT}`는 설치된 플러그인 절대 경로로 치환합니다. 현재 폴더에서 스크립트를 찾거나 즉석 변환 명령을 만들지 않습니다. `<작업실>`과 입출력은 고객이 지정한 절대 경로로 바꿉니다.

## 입력 체크리스트

출처 표기와 이용 허락은 별개입니다. 자료별 출처·허락 근거와 전재·변형·인쇄 배부·온라인 공개의 허용 범위를 기록합니다. 미확인 범위는 원장에게 확인받기 전 진행하지 않습니다.
- 과목·학년·단원, 권리 있는 지문·문항·보기·선지, 공식 정답 또는 원장 답안을 받습니다.
- 근거 위치(쪽·문단·식·개념)·허용 풀이법·학습 범위·분량을 확인합니다.
부족하면 묻습니다: “과목·학년과 허용 풀이법은 무엇인가요?” “정답·전체 문항·보기를 주실 수 있나요?” “근거 교재 위치나 개념은 무엇인가요?”

## 단계
1. 계획 보여 주기: 문항별 요구·제공 정답·근거·확인 필요를 정리합니다. 학생용 해설·강사용 검증표·이용 기록의 새 이름·분량을 보여 주고 승인받습니다.
2. 독립적으로 풀고 제공 정답과 대조합니다. 국어·영어는 문단·문장·어구, 수학은 조건→식→계산·대입, 과학은 법칙→변인·단위→자료, 사회는 개념→자료 조건으로 근거를 연결합니다.
3. 학생용은 정답→근거 위치→풀이 단계→오답 이유→주의점 순으로 씁니다. 객관식은 모든 오답을 반증하고 서술형은 허용 답·필수 요소·채점 기준을 나눕니다.
4. 강사용 표에서 근거·인용·계산을 재대조합니다. 제공 정답 충돌·복수 정답 가능성은 근거와 함께 보류합니다. 지문형 문제를 배경지식만으로 정당화하지 않습니다.
5. 새 해설·검증표·이용 기록을 열어 번호·정답·근거를 대조합니다. 원장 또는 해당 과목 교사 검수 범위를 기록합니다. PDF는 별도 `/ek-workroom:worksheet-pdf`로 계획합니다.

## 출력 양식
별도 `이용범위-새번호.md`: 자료명 | 출처 | 이용 허락 근거 | 전재·변형·인쇄 배부·온라인 공개 각각의 허용/미확인 | 원장 확인.
`학생해설-새번호.md`: # [과목·단원] 해설 초안 / ## 문항 1 / 정답 / 근거 위치 / 풀이 / 오답 이유 또는 채점 기준 / 주의점.
`해설검증-새번호.md`: # 해설 검증 / ## 문항별 판정표 / ## 정답 충돌·보류 / ## 교사 확인.
판정표: 문항·선지 | 판정 | 근거 위치·짧은 인용/식 | 판단 과정 | 오답 이유 | 확인 상태.
문항마다 자료명·발행처 또는 출제기관·연도/판본·쪽/문항번호를 적습니다. 공식 정답과 원장 답안의 출처·값을 구분합니다. 미제공 식별 정보는 확인 필요로 남깁니다. 학생용과 강사용은 별도 파일로 유지합니다.

## 품질 점검표
- [ ] 원문·발문·보기·선지를 빠짐없이 받았는가?
- [ ] 정답 근거 위치와 풀이가 연결되는가?
- [ ] 각 오답의 구체적 오류를 설명했는가?
- [ ] 직접 인용·수식·기호가 정확한가?
- [ ] 계산·단위·조건·허용 풀이 범위가 맞는가?
- [ ] 정답 충돌·복수 정답을 보류했는가?
- [ ] 근거 없는 출제 의도·학생 평가가 없는가?
- [ ] 교사 확인 전 초안 표시가 있는가?

## 더미 예시
입력: 가상 중1 수학 1번 “2x+3=7”, 선택지 ①1 ②2 ③3, 정답 ②.
출력 요약: ②, 2x=4이므로 x=2. ①은 대입 시 5, ③은 9로 불충족. 근거 ‘1번 주어진 식’, 학생해설과 별도 선지 검증표.

## 막힐 때 대처
정답이 없으면 추정으로 표시하고 확정하지 않습니다. 도식·수식 누락 문항은 보류합니다. HWPX는 `/ek-workroom:hwpx-read`, PDF는 고객 제공 텍스트를 받습니다. 근거 부족을 그럴듯한 설명으로 채우지 않습니다.

필요하면 `/ek-workroom:cross-check`로 브리프·대상 계획을 승인받아 검토합니다. 지적은 근거 대조 후 판정하고 반영은 새 파일로 승인받습니다.
