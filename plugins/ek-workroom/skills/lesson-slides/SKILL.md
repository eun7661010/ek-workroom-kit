# 수업 슬라이드

## 기본 원칙
잔여 개인정보 발견 시 해당 자료 처리를 중단하고 제거본을 요청합니다. 답변·검수표·다른 AI 입력에 재기재하지 않습니다.
고객이 직접 개인정보를 제거한 입력만 사용합니다. 학생정보 폴더·계정 파일을 열지 않습니다. 원본·인용·문학 원문을 보호합니다. 파일 변경 계획과 새 결과 이름을 보여 주고 승인 후 저장합니다. 기존 파일 덮어쓰기 금지. 결과 파일을 열어 확인하기 전 완료라고 말하지 않는다. 외부 검색·게시·발송·프로그램 설치를 하지 않습니다. 별도 외부 전송 도구를 연결하지 않으며 고객 본인 AI 구독에서 입력을 처리합니다. 비밀번호·인증 코드를 묻지 않습니다.

`${CLAUDE_PLUGIN_ROOT}`는 설치된 플러그인 절대 경로로 치환합니다. 현재 폴더에서 스크립트를 찾거나 즉석 변환 명령을 만들지 않습니다. `<작업실>`과 입출력은 고객이 지정한 절대 경로로 바꿉니다.

## 입력 체크리스트
- 과목·청중·목적·발표 시간·핵심 메시지와 근거 자료를 받습니다.
- 장 수, 학원명, 로컬 로고와 작업실 경로를 확인합니다.
부족하면 묻습니다: “누구에게 몇 분 동안 설명하나요?” “핵심 메시지와 근거는 무엇인가요?” “원하는 장 수가 있나요?”

## 단계
1. 계획 보여 주기: 10분이면 6~8장을 출발점으로 장별 제목·한 문장 메시지·근거·시간을 보입니다. HTML/PDF/메모 이름을 보여 주고 원장 승인을 받습니다.
2. `${CLAUDE_PLUGIN_ROOT}/templates/slides-16x9.html`을 새 이름으로 복사합니다. 즉석 CSS 금지. `.slide`를 반복해 한 장 한 메시지와 핵심 3개 이내로 채웁니다. 넘치면 장을 나눕니다.
3. 템플릿의 `.speaker-notes` 별도 섹션 형식으로 장 번호·설명·전환을 작성해 `발표메모-새번호.md`로 옮깁니다. 덱에는 빈 메모 섹션만 유지하고 내용을 제거합니다. 이미지·로고는 HTML과 같은 폴더 또는 하위 폴더 상대 경로만 씁니다.
4. 정적 HTML을 새로 저장하고 아래 명령으로 PDF를 만듭니다. 외부 자원·스크립트를 넣지 않습니다.
Windows:
```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "${CLAUDE_PLUGIN_ROOT}/scripts/ek-pdf.ps1" -Html "<작업실>/결과/새파일.html" -Pdf "<작업실>/결과/새파일.pdf"
```
Mac:
```sh
bash "${CLAUDE_PLUGIN_ROOT}/scripts/ek-pdf.sh" --html "<작업실>/결과/새파일.html" --pdf "<작업실>/결과/새파일.pdf"
```
5. HTML·PDF 모든 장과 별도 메모를 열어 장 수·가로 비율·잘림·장 번호를 대조합니다.

## 출력 양식
- `수업슬라이드-새번호.html/.pdf`: 수업은 제목 → 학습 목표 → 개념 → 예제 → 확인 문제 → 정리·다음 행동. 학부모 설명회는 목적 → 운영 내용 → 제공 근거 → 일정·비용 → 문의. 미확정 조건은 약속하지 않습니다. 목적에 따라 중간 장을 반복합니다.
- `발표메모-새번호.md`: # 발표자 메모 / ## 1장 제목 / 설명 / 질문 / 전환 / 예상 시간.
- 채팅: 파일 경로 / 장 수 / 총 발표 시간 / 열람 결과 / 확인 필요.

## 품질 점검표
- [ ] 제목이 해당 장 메시지를 드러내는가?
- [ ] 한 장에 핵심 주장이 하나인가?
- [ ] 수식·통계·단위·인용에 근거가 있는가?
- [ ] 16:9 가로 PDF이고 마지막 빈 장이 없는가?
- [ ] 본문 넘침·작은 글자·낮은 대비가 없는가?
- [ ] 상대 경로 그림이 표시되는가?
- [ ] 발표자 메모가 덱·PDF에 노출되지 않는가?
- [ ] 장별 시간 합이 발표 시간과 맞는가?

## 더미 예시
입력: 가상 배움학원 중1 과학, 밀도 복습, 5분·4장, 밀도=질량/부피.
출력 요약: 목표→식과 단위→두 물체 비교→확인 질문의 4장, 별도 메모와 4쪽 가로 PDF.

## 막힐 때 대처
근거 없는 통계는 확인 필요로 둡니다. 넘침은 장을 나누고 새 파일 계획을 승인받습니다. 종료 코드 2의 작업실 안내는 `ek-mode`를 확인하고 브라우저 없음이면 PDF 미완료로 기록합니다. 보호 폴더·숨김·하드링크를 쓰지 않으며 임시 서버·안전 옵션을 유지합니다. HTML 덱을 PPTX 편집본이라고 안내하지 않습니다.
