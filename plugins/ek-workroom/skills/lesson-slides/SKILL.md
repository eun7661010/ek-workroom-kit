# 고객 색과 양식으로 설명회·수업 슬라이드 초안을 만들 때 사용한다.

## 기본 원칙
고객이 직접 개인정보를 제거한 입력만 사용합니다. 학생정보 폴더·계정 파일은 열지 않습니다. 원본·인용·문학 원문은 보호합니다. 변경 파일과 내용을 먼저 보여 주고 승인 후 생성하며 기존 원본을 덮어쓰지 않습니다. 외부 검색·외부 전송·게시·발송·프로그램 설치는 하지 않습니다. 비밀번호·인증 코드를 묻지 않습니다. 필수 도구가 없으면 설치하지 않고 아래 수동 대안과 미완료 범위를 알립니다.

## 입력과 순서
1. 청중, 발표 목적, 발표 시간, 핵심 주장 세 개, 고객 색·로고·글꼴과 기존 양식 한 개를 받습니다. 설치된 글꼴만 씁니다.
2. 한 장 한 메시지로 제목→문제→근거→예시→다음 행동의 흐름을 제안합니다. 10분 발표는 6~8장 초안으로 시작하며 문단을 통째로 넣지 않습니다.
3. 16:9 HTML 덱 또는 기존 발표 도구용 ‘제목/핵심문장/도표 지시/발표자 메모’ 표를 만듭니다. 색은 고객 지정값이 없으면 흰 배경·짙은 글자·강조색 한 개를 씁니다.
4. 승인 뒤 새 파일로 만들고 기존 브라우저/발표 프로그램에서 화면·인쇄 PDF를 확인합니다. 학부모 정보·실제 성적·후기는 고객 승인된 비식별 근거만 씁니다.

## 출력·검수
슬라이드 초안, 발표자 메모, PDF(가능할 때), 사실 확인표를 제공합니다. 넘침·작은 글씨·색 대비·출처·발표 시간과 쪽수를 확인합니다.

## 도구가 없을 때
슬라이드 원고 표 또는 HTML을 제공합니다. PowerPoint 편집본이 필요하지만 변환 도구가 없으면 PPTX 미완료를 표시하며 설치하지 않습니다.
