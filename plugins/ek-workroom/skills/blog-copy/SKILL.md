# 블로그·카페에 사람이 붙여 넣을 원고와 HTML을 만들 때 사용한다.

## 기본 원칙
고객이 직접 개인정보를 제거한 입력만 사용합니다. 학생정보 폴더·계정 파일은 열지 않습니다. 원본·인용·문학 원문은 보호합니다. 변경 파일과 내용을 먼저 보여 주고 승인 후 생성하며 기존 원본을 덮어쓰지 않습니다. 외부 검색·외부 전송·게시·발송·프로그램 설치는 하지 않습니다. 비밀번호·인증 코드를 묻지 않습니다. 필수 도구가 없으면 설치하지 않고 아래 수동 대안과 미완료 범위를 알립니다.

## 입력과 순서
1. 검수된 원고, 제목, 소제목, 이미지 자리표시, 고객이 정한 색 한 개를 받습니다. 자동 로그인·발행은 하지 않습니다.
2. HTML에는 p/h2/strong/ul/li와 최소 inline style만 사용합니다. 스크립트·iframe·추적 링크·외부 글꼴을 넣지 않습니다. 사용자 본문은 &, <, >를 이스케이프합니다.
3. 예시 형식: `<p style="font-size:16px;line-height:1.8;margin:0 0 16px">문단</p>`. 문단 간 빈 줄이 사라지면 `<p style="height:16px;margin:0">&nbsp;</p>`를 씁니다. 복사할 텍스트본도 함께 만듭니다.
4. 생성 계획 승인 후 로컬 HTML을 새 파일로 만들고 브라우저에서 직접 엽니다. 고객이 편집기에 붙인 뒤 제목·문단·이미지 위치를 미리보기로 확인합니다.

## 출력·검수
텍스트본, 복사용 HTML, 사람용 붙여넣기 순서, 발행 전 확인표를 반환합니다. HTML 지원 여부가 편집기마다 다름을 안내합니다.

## 도구가 없을 때
브라우저 자동화 없이 고객이 파일을 열어 복사합니다. 서식이 깨지면 텍스트본으로 붙인 뒤 편집기에서 직접 꾸밉니다. 발행 완료로 표시하지 않습니다.
