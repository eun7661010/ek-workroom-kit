# 외부 전송 없이 한국어 띄어쓰기 후보를 검수할 때 사용한다.

## 기본 원칙
고객이 직접 개인정보를 제거한 입력만 사용합니다. 학생정보 폴더·계정 파일은 열지 않습니다. 원본·인용·문학 원문은 보호합니다. 변경 파일과 내용을 먼저 보여 주고 승인 후 생성하며 기존 원본을 덮어쓰지 않습니다. 외부 검색·외부 전송·게시·발송·프로그램 설치는 하지 않습니다. 비밀번호·인증 코드를 묻지 않습니다. 필수 도구가 없으면 설치하지 않고 아래 수동 대안과 미완료 범위를 알립니다.

## 입력과 순서
1. 고객이 붙여 넣은 비식별 텍스트를 받고 인용·시·지문·고유명사·과목 용어를 보호합니다.
2. 기존 Python과 kiwipiepy의 설치 여부만 확인합니다. 설치되어 있으면 `Kiwi().space(text)`로 메모리에서 후보를 만들고 원문과 어절별로 대조합니다. 결과를 원문에 바로 쓰지 않습니다. Python·패키지를 설치하지 않습니다.
3. 조사 붙이기, 의존 명사 띄기, 보조 용언 허용 표기, 고유명사를 구분해 ‘원문 | 후보 | 이유 | 확신도’로 정리합니다. 형태소 분석 결과가 문맥보다 우선하지 않습니다.
4. 높은 확신도 후보만 승인 후 새 파일에 적용하고 보호 구간 제외 건수를 표시합니다.

## 출력·검수
후보 표, 보호 구간 제외 건수, 사용 엔진/수동 여부, 미확정 어휘를 반환합니다. 예: ‘할수 있다’→‘할 수 있다’는 후보, 학교·교재 이름은 보호합니다.

## 도구가 없을 때
‘Kiwi 미설치: 오프라인 엔진 검사 미완료’라고 명시하고 수동 언어 검토 후보만 제공합니다. 웹 맞춤법 사이트에 보내지 않습니다.
