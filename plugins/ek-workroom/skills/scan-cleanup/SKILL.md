# 기울거나 누런 스캔 PDF를 원본 보존하며 정리할 때 사용한다.

## 기본 원칙
고객이 직접 개인정보를 제거한 입력만 사용합니다. 학생정보 폴더·계정 파일은 열지 않습니다. 원본·인용·문학 원문은 보호합니다. 변경 파일과 내용을 먼저 보여 주고 승인 후 생성하며 기존 원본을 덮어쓰지 않습니다. 외부 검색·외부 전송·게시·발송·프로그램 설치는 하지 않습니다. 비밀번호·인증 코드를 묻지 않습니다. 필수 도구가 없으면 설치하지 않고 아래 수동 대안과 미완료 범위를 알립니다.

## 입력과 순서
1. 개인정보 없는 스캔 PDF 한 개, 쪽수, 문제(기울기·여백·누런 배경)를 받습니다. OCR이나 원문 재작성과 영상 보정을 구분합니다.
2. 고객 PC에 이미 있는 로컬 PDF 편집기의 회전·자르기·명도 기능을 확인합니다. 설치·온라인 업로드를 하지 않습니다. 스캔 원본은 별도 보존합니다.
3. 한 쪽의 미리보기 계획을 승인받고 복사본에서 기울기→여백→밝기 순서로 조정합니다. 글자가 얇아지면 대비를 되돌립니다. 자동 보정의 실제 설정은 사용하는 도구 도움말에 따릅니다.
4. 원장님이 작은 각주·기호·밑줄·도형 보존을 확인한 뒤 같은 값으로 나머지 쪽을 처리합니다. 쪽별 크기·방향이 다르면 일괄 자르지 않습니다.

## 출력·검수
새 정리 PDF, 적용한 값과 도구, 전후 한 쪽 비교, 누락·잘림 검수표입니다. 글자 추출 성공을 주장하지 않습니다.

## 도구가 없을 때
‘자동 보정 미완료’로 표시하고 기존 PDF 뷰어의 보기 회전·인쇄 확대 등 수업 중 수동 대안을 안내합니다. 서버나 웹 PDF 서비스로 올리지 않습니다.
