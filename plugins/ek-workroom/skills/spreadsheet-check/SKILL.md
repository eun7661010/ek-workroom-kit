# 비식별 엑셀·표를 정리하거나 예외 항목을 대조할 때 사용한다.

## 기본 원칙
고객이 직접 개인정보를 제거한 입력만 사용합니다. 학생정보 폴더·계정 파일은 열지 않습니다. 원본·인용·문학 원문은 보호합니다. 변경 파일과 내용을 먼저 보여 주고 승인 후 생성하며 기존 원본을 덮어쓰지 않습니다. 외부 검색·외부 전송·게시·발송·프로그램 설치는 하지 않습니다. 비밀번호·인증 코드를 묻지 않습니다. 필수 도구가 없으면 설치하지 않고 아래 수동 대안과 미완료 범위를 알립니다.

## 입력과 순서
1. 개인정보 없는 표와 열 뜻, 비교 기준을 확인합니다. 학생은 번호만, 연락처·실명은 빼고 금액 대조는 가상 데이터로만 세팅합니다. 원본을 보존하고 새 결과 파일 계획을 승인받습니다.
2. 날짜 형식·공백·빈칸·중복 ID를 표준화합니다. ID는 숫자로 강제 변환하지 않아 앞자리 0을 보존합니다. 금액은 통화기호·쉼표를 제거한 정수로 비교합니다.
3. 대조는 고유 ID로 먼저 결합합니다. 이름 유사도로 자동 확정하지 않습니다. 일치/한쪽 누락/금액 불일치/중복/모호함으로 나눕니다. 합계와 행 수를 입력과 대조합니다.
4. 수식 예시는 기존 Excel에서 `COUNTIF`로 중복 표시, `SUMIF`로 번호별 금액 합계입니다. 동명이인이나 분할 입금은 사람이 확인합니다. CSV 출력 시 =,+,-,@로 시작하는 텍스트 셀의 수식 실행 위험을 확인합니다.

## 출력·검수
정리본, 예외 표(번호·이유·확인 필요), 합계 대조, 바꾼 열 목록을 제공합니다. 실제 원장·수납 시스템은 수정하지 않습니다.

## 도구가 없을 때
기존 Excel/스프레드시트로 수동 필터·수식을 안내하거나 비식별 CSV 텍스트로 진행합니다. xlsx 엔진이 없으면 xlsx 생성 미완료를 표시합니다. 실데이터 첫 수납 대조는 세션 뒤 고객이 단독 수행합니다.
