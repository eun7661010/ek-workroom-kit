# 개인정보 없는 CSV의 중복·누락·합계와 대조 오류를 검수할 때 사용한다.

## 기본 원칙
고객이 직접 개인정보를 제거한 입력만 사용합니다. 학생정보 폴더·계정 파일을 열지 않습니다. 원본·인용·문학 원문을 보호합니다. 파일 변경 계획과 새 결과 이름을 보여 주고 승인 후 저장합니다. 기존 파일 덮어쓰기 금지. 결과 파일을 열어 확인하기 전 완료라고 말하지 않는다. 외부 검색·게시·발송·프로그램 설치를 하지 않습니다. 별도 외부 전송 도구를 연결하지 않으며 고객 본인 AI 구독에서 입력을 처리합니다. 비밀번호·인증 코드를 묻지 않습니다.

`${CLAUDE_PLUGIN_ROOT}`는 설치된 플러그인 절대 경로로 치환합니다. 현재 폴더에서 스크립트를 찾거나 즉석 변환 명령을 만들지 않습니다. `<작업실>`과 입출력은 고객이 지정한 절대 경로로 바꿉니다.

## 입력과 순서
1. 입력은 CSV입니다. 엑셀 파일만 있으면 고객에게 **엑셀에서 CSV UTF-8로 저장**한 별도 사본을 요청합니다. 엑셀이나 변환 패키지를 설치하지 않습니다.
2. 열 뜻·행 수·비교 기준을 받습니다. 학생은 가상 번호만 쓰고 실명·연락처를 제외합니다. 금액 세팅은 가상 데이터로 시험합니다.
3. 날짜·공백·빈칸·중복 ID를 점검합니다. ID 앞자리 0을 보존하며 고유 ID로 결합하고 이름 유사도로 일치를 확정하지 않습니다.
4. 일치/한쪽 누락/금액 불일치/중복/모호함 표와 입력·출력 행 수·합계를 대조합니다. CSV 따옴표와 쉼표를 보존합니다. =,+,-,@로 시작하는 텍스트는 수식으로 실행되지 않게 처리 계획을 보입니다.
5. 새 CSV 정리본과 Markdown 검수표를 저장하고 고객이 엑셀에서 열어 번호·한글·행 수·합계를 확인합니다. 실제 수납 원장·시스템은 수정하지 않습니다.

## 선택 교차 검토
필요하면 `/ek-workroom:cross-check`의 브리프 계획→승인→저장 순서를 따르고 승인된 브리프와 새 결과 이름으로만 실행합니다.
Windows:
```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "${CLAUDE_PLUGIN_ROOT}/scripts/ek-codex-review.ps1" -Workspace "<작업실>" -Brief "<작업실>/검토/검토요청-새번호.md" -Out "<작업실>/검토/검토결과-새번호.md"
```
Mac:
```sh
bash "${CLAUDE_PLUGIN_ROOT}/scripts/ek-codex-review.sh" --workspace "<작업실>" --brief "<작업실>/검토/검토요청-새번호.md" --out "<작업실>/검토/검토결과-새번호.md"
```
