# 고객 양식으로 학습지 HTML과 인쇄 PDF를 만들 때 사용한다.

## 기본 원칙
고객이 직접 개인정보를 제거한 입력만 사용합니다. 학생정보 폴더·계정 파일은 열지 않습니다. 원본·인용·문학 원문은 보호합니다. 변경 파일과 내용을 먼저 보여 주고 승인 후 생성하며 기존 원본을 덮어쓰지 않습니다. 외부 검색·외부 전송·게시·발송·프로그램 설치는 하지 않습니다. 비밀번호·인증 코드를 묻지 않습니다. 필수 도구가 없으면 설치하지 않고 아래 수동 대안과 미완료 범위를 알립니다.

## 입력과 순서
1. 권리 확인된 원문 텍스트, 고객 양식 한 개, 학년·제목·문제·정답을 받습니다. 학생용과 정답용을 별도로 구성합니다.
2. A4 기본 HTML에 `@page{size:A4;margin:16mm}`와 `body{font-family:system-ui;line-height:1.7;word-break:keep-all}`를 적용합니다. 문항은 `break-inside:avoid`, 긴 표는 행 단위로 나누고 고정 높이로 본문을 자르지 않습니다.
3. 생성 파일과 페이지 계획을 미리 보여 주고 승인 뒤 HTML 두 개를 만듭니다. 서체·로고는 고객이 이미 가진 로컬 파일만 씁니다. 원문은 그대로 유지합니다.
4. 기존 브라우저에서 열기→인쇄→PDF로 저장→A4/배율 확인을 고객이 수행합니다. 머리글/바닥글 URL을 끄고 저장 후 전 페이지를 엽니다.

## 출력·검수
학생용 HTML/PDF, 정답용 HTML/PDF, 쪽별 검수표입니다. 글자 깨짐·넘침·빈 페이지·학생용 정답 노출·원문 누락을 검사합니다.

## 도구가 없을 때
브라우저가 있으면 수동 인쇄로 진행합니다. PDF 저장이 안 되면 HTML까지만 제공하고 PDF 미완료를 명시합니다. 렌더러를 설치하지 않습니다.
