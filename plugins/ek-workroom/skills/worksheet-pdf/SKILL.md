# A4 학습지와 정답지

## 기본 원칙
잔여 개인정보 발견 시 해당 자료 처리를 중단하고 제거본을 요청합니다. 답변·검수표·다른 AI 입력에 재기재하지 않습니다.
고객이 직접 개인정보를 제거한 입력만 사용합니다. 학생정보 폴더·계정 파일을 열지 않습니다. 원본·인용·문학 원문을 보호합니다. 파일 변경 계획과 새 결과 이름을 보여 주고 승인 후 저장합니다. 기존 파일 덮어쓰기 금지. 결과 파일을 열어 확인하기 전 완료라고 말하지 않는다. 외부 검색·게시·발송·프로그램 설치를 하지 않습니다. 별도 외부 전송 도구를 연결하지 않으며 고객 본인 AI 구독에서 입력을 처리합니다. 비밀번호·인증 코드를 묻지 않습니다.

`${CLAUDE_PLUGIN_ROOT}`는 설치된 플러그인 절대 경로로 치환합니다. 현재 폴더에서 스크립트를 찾거나 즉석 변환 명령을 만들지 않습니다. `<작업실>`과 입출력은 고객이 지정한 절대 경로로 바꿉니다.

## 입력 체크리스트

출처 표기와 이용 허락은 별개입니다. 자료별 출처·허락 근거와 전재·변형·인쇄 배부·온라인 공개의 허용 범위를 기록합니다. 미확인 범위는 원장에게 확인받기 전 진행하지 않습니다.
- 사용 권리가 있는 원문·문항·보기·정답·출처, 학원명·과목·학년·단원을 받습니다.
- 작업실 경로, 목표 쪽수·답안 공간, 로컬 그림·로고를 확인합니다.
부족하면 묻습니다: “어느 학년·과목·단원인가요?” “문항·정답·출처를 함께 주실 수 있나요?” “답안 공간과 목표 쪽수는 얼마인가요?”

## 단계
1. 계획 보여 주기: 문항 수와 정답 대응표, 학생용/정답용 HTML·PDF 네 파일과 별도 이용 기록 이름·예상 쪽수를 보여 주고 원장 승인을 받습니다.
2. `${CLAUDE_PLUGIN_ROOT}/templates/worksheet-a4.html`과 `answer-a4.html`을 새 이름으로 복사합니다. 즉석 CSS 금지. 텍스트·기존 블록만 교체·반복합니다. 학생용에 `.answer-only` 내용을 넣지 않습니다.
3. 원문 그대로 문항별 `.question`에 발문·보기·선지·답안 칸을 넣습니다. 정답·해설은 정답용 `.answer-only`에만 넣습니다. 한 쪽 초과 문항·해설은 축약 없이 승인된 경계로 나누고 번호·‘계속’을 반복합니다. 수식은 양식의 분수·첨자·근호 블록 또는 제공 이미지로 넣고 분수선·첨자·근호 범위를 원본과 대조합니다.
4. 각 HTML에 아래 `ek-pdf`를 한 번씩 실행합니다. 이미지·로고는 HTML과 같은 폴더 또는 하위 폴더 상대 경로만 씁니다. 외부 URL·상위 경로·스크립트는 금지합니다.
Windows:
```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "${CLAUDE_PLUGIN_ROOT}/scripts/ek-pdf.ps1" -Html "<작업실>/결과/새파일.html" -Pdf "<작업실>/결과/새파일.pdf"
```
Mac:
```sh
bash "${CLAUDE_PLUGIN_ROOT}/scripts/ek-pdf.sh" --html "<작업실>/결과/새파일.html" --pdf "<작업실>/결과/새파일.pdf"
```
5. HTML 두 개와 PDF 모든 쪽을 열어 확인합니다. 실제 쪽수·보류 사항을 기록하고 원장 검수를 받습니다.

## 출력 양식
별도 `이용범위-새번호.md`: 자료명 | 출처 | 이용 허락 근거 | 전재·변형·인쇄 배부·온라인 공개 각각의 허용/미확인 | 원장 확인.
- `학습지-학생용-새번호.html/.pdf`: 제목 → 학원명·과목·단원·학년·반·이름 빈칸 → 학습 안내 → 번호별 문항·보기·답안 칸.
- `학습지-정답용-새번호.html/.pdf`: 제목 → 단원 정보 → 정답표 → 문항별 정답·근거·오답 이유.
- 채팅: 파일 경로 / 문항 수 / PDF 쪽수 / 열람 결과 / 확인 필요.

## 품질 점검표
- [ ] 원문·수식·기호·단위가 입력과 같은가?
- [ ] 문항 번호·보기·선지 순서에 누락이 없는가?
- [ ] 학생용 본문·숨김 요소·주석에도 정답이 없는가?
- [ ] 정답과 해설의 번호가 대응하는가?
- [ ] A4에서 문항·해설·표·그림·답안 칸의 쪽 경계와 계속 표기·빈 쪽을 확인했는가?
- [ ] 한글과 상대 경로 그림이 표시되는가?
- [ ] 답안 공간이 충분하고 개인정보가 없는가?

## 더미 예시
입력: 원장이 탐색기로 작업실 `입력` 폴더에 `E-입력.txt`를 저장합니다. 자체 작성 더미 “2x+3=7”, 정답 x=2. 파일이 없으면 탐색하지 않고 정확한 위치를 확인합니다.
출력 요약: `결과/학습지-학생용-001.html/.pdf`, `결과/학습지-정답용-001.html/.pdf`와 각 1쪽 열람 기록. `새번호`는 빈 번호로 바꾸며 요청한 이름이 있으면 그 이름을 씁니다. 후속 검토는 “방금 만든 학생용·정답용 HTML”의 실제 경로를 사용합니다.

## 막힐 때 대처
정답·그림이 없으면 확인 필요로 두고 최종본을 보류합니다. HTML은 `ek-mode` 작업실 안에 둡니다. 보호 폴더와 겹치는 위치·숨김·하드링크는 쓰지 않습니다. 종료 코드 2의 작업실 안내는 `ek-mode`로, 브라우저 없음은 수동 인쇄 안내와 PDF 미완료로 남깁니다. 임시 서버·안전 옵션을 완화하지 않습니다.
