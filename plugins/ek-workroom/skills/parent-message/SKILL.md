# 학부모 안내문·상담 답장 초안을 작성할 때 사용한다.

## 기본 원칙
고객이 직접 개인정보를 제거한 입력만 사용합니다. 학생정보 폴더·계정 파일은 열지 않습니다. 원본·인용·문학 원문은 보호합니다. 변경 파일과 내용을 먼저 보여 주고 승인 후 생성하며 기존 원본을 덮어쓰지 않습니다. 외부 검색·외부 전송·게시·발송·프로그램 설치는 하지 않습니다. 비밀번호·인증 코드를 묻지 않습니다. 필수 도구가 없으면 설치하지 않고 아래 수동 대안과 미완료 범위를 알립니다.

## 입력과 순서
1. 목적, 익명 대상(반 번호 등), 확정된 일정·금액·문의 방식, 원하는 길이를 받습니다. 문체 참고는 개인정보를 지운 기존 글 3~5개만 사용합니다.
2. 전달 사실을 먼저 표로 정리합니다. 제공되지 않은 날짜·성적·학생 태도·환불 조건은 ‘확인 필요’로 둡니다.
3. ‘인사→핵심 안내→이유→고객이 할 일→마무리’ 순서로 300자 안팎 기본안과 120자 안팎 짧은 안을 작성합니다. 상담 답장은 공감 한 문장 뒤 사실·다음 행동을 씁니다.
4. 원장님이 대상·날짜·시간·금액을 검수합니다. 성적 향상 보장, 불안 자극, 과장 표현을 지웁니다.

## 출력·검수
사실 확인표, 기본안/짧은 안, 빠진 정보, 사람이 발송할 때 확인할 세 항목을 반환합니다. 실명·연락처는 넣지 않습니다. 실제 발송은 원장님이 합니다.

## 도구가 없을 때
텍스트만으로 완료할 수 있습니다. 문자·알림톡 도구 연결과 자동 발송은 제공하지 않습니다.
