# 기존 도구로 HWP·HWPX를 읽거나 변환할 때 사용한다.

## 기본 원칙
고객이 직접 개인정보를 제거한 입력만 사용합니다. 학생정보 폴더·계정 파일은 열지 않습니다. 원본·인용·문학 원문은 보호합니다. 변경 파일과 내용을 먼저 보여 주고 승인 후 생성하며 기존 원본을 덮어쓰지 않습니다. 외부 검색·외부 전송·게시·발송·프로그램 설치는 하지 않습니다. 비밀번호·인증 코드를 묻지 않습니다. 필수 도구가 없으면 설치하지 않고 아래 수동 대안과 미완료 범위를 알립니다.

## 입력과 순서
1. 고객이 지정한 개인정보 없는 파일 한 개와 읽기/변환 목적을 확인합니다. 암호 파일·학생 명단은 열지 않습니다. 원본 해시와 출력 이름을 고객 로컬에 기록하는 계획을 보여 줍니다.
2. 기존 `kordoc --help` 또는 고객의 한컴오피스에서 지원 형식·출력 옵션을 확인합니다. 도움말에 없는 명령·자동화를 만들지 않습니다. 설치·업그레이드는 하지 않습니다.
3. 승인 후 새 출력 경로로 추출 또는 변환합니다. 원본은 수정하지 않습니다. 표·각주·수식·그림은 변환 손실 가능 항목으로 표시합니다.
4. 고객이 원본과 변환본의 페이지, 제목, 표 셀, 정답, 글자 누락을 대조합니다. Markdown→HWPX는 설치된 도구가 실제 지원하고 한컴에서 열리는 경우에만 완료로 봅니다.

## 출력·검수
변환본, 도구·버전, 손실 가능 항목, 원본 대조표를 제공합니다. PDF로 저장만 한 경우 HWPX 편집본 완료라고 말하지 않습니다.

## 도구가 없을 때
‘변환 미완료: 지원 도구 없음’으로 표시합니다. 고객이 한컴에서 텍스트 또는 PDF로 다른 이름 저장하는 수동 경로를 안내하거나 텍스트 붙여넣기만 받습니다.
