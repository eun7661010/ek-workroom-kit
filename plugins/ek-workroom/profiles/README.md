# 고객 프로필
`example.json`을 고객 PC의 개인정보 없는 작업실에 복사해 수정합니다. `profile.schema.json`을 기준으로 필수 항목을 확인합니다. code A~E와 template A.md~E.md의 글자는 같아야 합니다. 한 세션은 업무 한 개입니다.
학생 폴더 절대 경로는 차단 설정에만 쓰며 파일을 열지 않습니다. 프로필 자체도 판매자 AI에 보내지 않습니다. 이름·연락처·이메일·비밀번호·인증 코드는 추가하지 않습니다.
`accountLabel`은 수동 별칭이며 로그인 확인이 아닙니다. 실제 계정은 고객이 `/status`로 확인합니다. Mac은 os를 macos로, 차단 경로를 고객이 확인한 절대 경로로 바꿉니다.
